# 検証動画

新しく追加した機能が正しく動くかを確認するための素材です。
AI 動画生成 (Magnific / Seedance 2.0) で作成し、**検証素材として成立しているかを
ffprobe で実測して確認済み**です。

すべて 1920x1080 / 24fps / 音声トラック付き。

| ファイル | 尺 | 対象機能 | 実測した特性 | なぜこの素材か |
|---|---|---|---|---|
| `01_オブジェクト除去_歩行者が横切る固定カメラ.mp4` | 8.0秒 | オブジェクト除去 | フレーム平均輝度の標準偏差 **0.15**（＝背景が完全静止） | 背景が動かないので、人物を消した跡に「本来そこにあったはずの背景」が正しく復元されたかを目視で照合できる |
| `02_フリッカー除去_蛍光灯が明滅する倉庫.mp4` | 6.0秒 | フリッカー除去 | フレーム平均輝度が **29.9〜56.5** で振れる（標準偏差 **6.71**） | 明滅が実際に入っているので、補正後に輝度の振れ幅が潰れたかどうかを数値でもグラフでも判定できる |
| `03_3Dライト_平坦照明の石膏像.mp4` | 5.0秒 | 3D ライト | フレーム平均輝度の標準偏差 **0.11**（＝陰影がほぼ無い平坦照明） | 元の絵に陰影が無いため、ライトを足して生じた陰影が「純粋に新規分」として見分けられる |
| `04_音声分離_カフェ騒音下の会話.mp4` | 8.0秒 | 音声分離（スピーチ強調） | 音声 mean **-32.0dB** / max **-13.1dB**、会話と騒音が重畳 | 会話と定常騒音が混ざっているので、「音声のみ」と「背景のみ」が相補的に分離できたかを耳で判定できる |

## 使い方

各機能の具体的な検証手順は、リポジトリ直下の **`検証手順.md`** を参照してください。
メニューのたどり方・前提条件・「効いたことをどう見分けるか」をまとめてあります。

## 補足

- これらは**検証専用**の素材です。アプリの動作確認以外の用途は想定していません。
- 実測値は `ffprobe -f lavfi -i "movie=<file>,signalstats"` で取得したものです。
  素材を差し替える場合は、同じ観点（背景の静止度／明滅の振れ幅／陰影の有無／音声と騒音の重畳）を
  満たしているか実測してから使ってください。
