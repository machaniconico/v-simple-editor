  1. ツールバー (画面上部のアイコン列)
================================================================================

左から順に配置されています。アイコンの上にマウスを置くとツールチップが出ます。

▼ ファイル操作
  ┌──────────────────────────────────────────────────────────────────┐
  │ [新規]                                                            │
  │   新しい空のプロジェクトを作成します。                             │
  │   解像度 (1920x1080 など)、フレームレート (30fps / 60fps など)、   │
  │   プロジェクト名を設定するダイアログが開きます。                   │
  │   ショートカット: Ctrl + N                                         │
  └──────────────────────────────────────────────────────────────────┘
  ┌──────────────────────────────────────────────────────────────────┐
  │ [開く]                                                            │
  │   動画ファイルを開きます。                                         │
  │   対応形式: MP4, MKV, MOV, WebM, FLV                               │
  │   開いたファイルは自動的にタイムラインに配置されます。             │
  │   ショートカット: Ctrl + O                                         │
  └──────────────────────────────────────────────────────────────────┘
  ┌──────────────────────────────────────────────────────────────────┐
  │ [保存]                                                            │
  │   現在のプロジェクトを .veditor ファイルに保存します。             │
  │   タイムラインのクリップ配置、エフェクト、設定がすべて保存されます。│
  │   ショートカット: Ctrl + S                                         │
  └──────────────────────────────────────────────────────────────────┘

▼ 編集操作
  ┌──────────────────────────────────────────────────────────────────┐
  │ [元に戻す]                                                        │
  │   直前の操作を取り消します (カット、削除、速度変更など)。          │
  │   ショートカット: Ctrl + Z                                         │
  └──────────────────────────────────────────────────────────────────┘
  ┌──────────────────────────────────────────────────────────────────┐
  │ [やり直し]                                                        │
  │   元に戻した操作をもう一度実行します。                             │
  │   ショートカット: Ctrl + Shift + Z                                 │
  └──────────────────────────────────────────────────────────────────┘

▼ クリップ編集
  ┌──────────────────────────────────────────────────────────────────┐
  │ [分割]                                                            │
  │   現在の再生ヘッド位置でクリップを 2 つに分割します。              │
  │   不要部分の切り取りや、クリップの中間にエフェクトを差し込む時に  │
  │   使用します。                                                     │
  │   ショートカット: S                                                │
  └──────────────────────────────────────────────────────────────────┘
  ┌──────────────────────────────────────────────────────────────────┐
  │ [削除]                                                            │
  │   選択中のクリップをタイムラインから削除します。                   │
  │   ショートカット: Delete                                           │
  │                                                                    │
  │   リップル削除 (削除後に後続クリップを詰める):                     │
  │   ショートカット: Shift + Delete                                   │
  └──────────────────────────────────────────────────────────────────┘
  ┌──────────────────────────────────────────────────────────────────┐
  │ [コピー]                                                          │
  │   選択中のクリップをクリップボードに複製します。                   │
  │   ショートカット: Ctrl + C                                         │
  └──────────────────────────────────────────────────────────────────┘
  ┌──────────────────────────────────────────────────────────────────┐
  │ [貼付]                                                            │
  │   クリップボードのクリップを現在の位置に貼り付けます。             │
  │   ショートカット: Ctrl + V                                         │
  └──────────────────────────────────────────────────────────────────┘

▼ エフェクト・装飾
  ┌──────────────────────────────────────────────────────────────────┐
  │ [テキスト]                                                        │
  │   テロップ・字幕・タイトルを追加します。                           │
  │   フォント、色、アウトライン、影、アニメーションを設定できます。   │
  │   ショートカット: T                                                │
  └──────────────────────────────────────────────────────────────────┘
  ┌──────────────────────────────────────────────────────────────────┐
  │ [色補正]                                                          │
  │   明るさ、コントラスト、彩度、色相、露出、ホワイトバランス、       │
  │   ハイライト/シャドウ、ガンマを調整します。変更はリアルタイムで    │
  │   GPU シェーダーによってプレビューに反映されます。                 │
  │   ショートカット: Ctrl + G                                         │
  └──────────────────────────────────────────────────────────────────┘
  ┌──────────────────────────────────────────────────────────────────┐
  │ [効果]                                                            │
  │   ビデオエフェクト (ブラー、シャープ、モザイク、ビネットなど) を   │
  │   選択クリップに適用します。                                       │
  │   ショートカット: Ctrl + Shift + F                                 │
  └──────────────────────────────────────────────────────────────────┘
  ┌──────────────────────────────────────────────────────────────────┐
  │ [マーカー]                                                        │
  │   現在の再生ヘッド位置にマーカーを付けます。チャプター作成や       │
  │   後で戻ってきたい場所の目印として使います。                       │
  │   ショートカット: Ctrl + M                                         │
  └──────────────────────────────────────────────────────────────────┘

▼ 出力・録画
  ┌──────────────────────────────────────────────────────────────────┐
  │ [出力]                                                            │
  │   タイムラインの内容を動画ファイルとしてエクスポートします。       │
  │   コーデック (H.264 / H.265 / AV1 など)、ビットレート、解像度、    │
  │   FPS、音声コーデックなどを設定できます。                          │
  │   ショートカット: Ctrl + E                                         │
  └──────────────────────────────────────────────────────────────────┘
  ┌──────────────────────────────────────────────────────────────────┐
  │ [録画]                                                            │
  │   画面録画を開始します。録画した動画は自動でタイムラインに         │
  │   追加されます。停止は Tools メニューから。                        │
  └──────────────────────────────────────────────────────────────────┘


================================================================================
  2. メニューバー
================================================================================

--------------------------------------------------------------------------------
  2-1. ファイル メニュー
--------------------------------------------------------------------------------

  ● 新規プロジェクト (Ctrl+N)
    新しいプロジェクトを作成します。最初に解像度とフレームレートを決めます。

  ● ファイルを開く (Ctrl+O)
    動画ファイルを直接読み込み、タイムラインに追加します。

  ● 最近使ったファイル
    過去に開いた動画・プロジェクトの一覧から選んで再度開けます。

  ● プロジェクトを開く (Ctrl+Shift+O)
    .veditor プロジェクトファイルを開きます。

  ● プロジェクトを保存 (Ctrl+S)
    現在のプロジェクトを上書き保存します。

  ● 名前を付けて保存 (Ctrl+Shift+S)
    別名で保存します。

  ● 保存版と比較…
    保存済みの .veditor ファイルを選ぶと、現在のタイムラインとの構造差分 (追加 / 削除 / 移動 /
    トリム / プロパティ変更 / 効果変更 / トランジション変更 / トラック設定変更) を一覧します。
    行をダブルクリックすると該当クリップを選択して再生ヘッドが移動します (削除済みは移動不可)。
    微小な数値差は同一扱いです。MCP では compare_project が同じ比較を返します。

  ● マルチカメラ...
    複数カメラの素材をアングルとして登録し、「音声で同期」ボタンで音声の相関から
    アングル間のオフセットを自動推定します (基準は最初のアングル)。推定値は各行の
    ms 欄に表示され、手で微調整できます。適用するとマルチカム EDL に反映されます。
  ● プロジェクトを収集 (Collect Files)...
    プロジェクトが参照する素材 (映像・音声・画像・LUT・パーティクル設定・ネストした
    シーケンス) を 1 つのフォルダへ集めます。対象の列挙は「メディアの再リンク」と
    同じ経路なので、収集漏れがありません。
  ● メディアの再リンク (自動)
    プロジェクトを開いたときに見つからない素材があると、再リンクダイアログが出ます。
    フォルダを指定すると同名ファイルを一括で再リンクし、リンクした音声やネストした
    シーケンスの参照もまとめて更新します。Ctrl+Z 1 回で戻せます。
  ● エクスポート (Ctrl+E)
    動画ファイルとして書き出します (コーデック・ビットレート指定)。
    「レート制御」で ビットレート / 品質 (CRF) を選べます。CRF は H.264 / H.265 / VP9 が 0〜51 (既定 23)、
    AV1 が 0〜63 (既定 30) で、小さいほど高画質・大容量です (ProRes では選べません)。AV1 の CRF で
    ハードウェアエンコーダが使えない環境ではソフトウェア (libsvtav1) に自動で切り替わります。
    「音声のみ (映像なし)」にチェックすると m4a (AAC) / wav (PCM 16bit) / mp3 の音声ファイルだけを
    書き出します。中間ミックスは PCM なので損失圧縮は最後の 1 回だけです。
    レンダーキューに入れてもレート制御 / CRF / 音声のみ の設定は保持されます。

  ● タイムコード焼き込み設定…
    プレビューと動画書き出しに表示するタイムコードの位置・書式を設定します。
    無効時は書き出しが従来と byte-identical になります。

  ● Remotion形式でエクスポート
    Remotion (React ベースの動画生成フレームワーク) のプロジェクト形式で
    出力します。Web 上で動的な動画を生成したい場合に便利です。

  ● 終了 (Ctrl+Q)
    アプリケーションを終了します。


--------------------------------------------------------------------------------
  2-2. 編集 メニュー
--------------------------------------------------------------------------------

  ● 元に戻す (Ctrl+Z) / やり直す (Ctrl+Shift+Z)
  ● クリップをコピー (Ctrl+C) / 貼り付け (Ctrl+V)
  ● 複製 (Ctrl+D)
    選択したクリップをそれぞれの直後に複製します。リンクした映像・音声は一緒に
    複製され、新しいリンク番号が付きます。空きが足りなければトラック末尾に入ります。
    Ctrl+Z 1 回で戻ります。
  ● すべて選択 (Ctrl+A) / 再生ヘッド以降を選択 / 再生ヘッド以前を選択
    ロック中・非表示のトラックを除く全クリップ、または再生ヘッドより後ろ (前) の
    クリップをまとめて選択します (再生ヘッドにかかるクリップも含みます)。
  ● 再生ヘッドで分割 (S)
  ● 全トラックを再生ヘッドで分割 (Ctrl+Shift+K)
    再生ヘッド位置にある全トラックのクリップを一度に分割します (ブレードオール)。
    ロック中のトラックは対象外、リンクは維持されます。Ctrl+Z 1 回で戻ります。
  ● クリップを削除 (Delete) / リップル削除 (Shift+Delete)
  ● リフト (ギャップを残して削除)
    選択クリップを削除し、後続のクリップは動かしません (空きが残ります)。
  ● 1フレーム左へ移動 (Alt+←) / 1フレーム右へ移動 (Alt+→)
  ● 10フレーム左へ移動 (Alt+Shift+←) / 10フレーム右へ移動 (Alt+Shift+→)
    選択クリップをフレーム単位 (1/fps 秒) で動かします (ナッジ)。隣のクリップに
    ぶつかる場合はステータスバーに「指定位置へ移動できません。候補: N 秒」、
    0 秒より前には行かず「ナッジ位置を N 秒に調整しました。」と出ます。
    リンクしたクリップは一緒に動き、ロック中のトラックは動きません。1 回の
    ナッジ = Ctrl+Z 1 回。
  ● すべてのギャップを詰める
    全トラック (ロック中を除く) で同時に空いている区間だけをまとめて詰めます。
    1 つのトラックだけが空いている区間は、他のトラックがずれてしまうので詰めません。
    Ctrl+Z 1 回で戻ります。
  ● スナップ切替 (N)
    クリップ境界にピッタリ吸着するかどうかを切り替えます。細かい調整を
    したい時はオフ、綺麗に並べたい時はオンにします。
  ● 再生速度を設定
    選択クリップの再生速度を 0.25x ～ 4.0x の間で指定します。
  ● マッチフレーム (F)
    再生ヘッド位置のクリップを、対応するソース時刻でソースモニターに
    開きます。速度変更・逆再生・タイムリマップを反映した時刻になります。
  ● クリップをメディアプールの素材で置き換え
    選んだクリップの位置とトリムを保ったまま、メディアプールで選択中の
    素材へ差し替えます。新素材が短い場合は警告が出ます。クリップ右クリック
    メニューの「置き換え」からも同じ操作ができます。
  ● 逆再生
    選んだクリップを後ろから再生します (チェックで ON/OFF)。リンクした
    映像・音声クリップにも同時に適用され、速度変更と併用できます。
  ● キーボードショートカット (Ctrl+Alt+K)
    ショートカットのカスタマイズダイアログを開きます。


--------------------------------------------------------------------------------
  2-3. 表示 メニュー
--------------------------------------------------------------------------------

  ● 拡大 / 縮小 (Ctrl+= / Ctrl+-)
    タイムラインのズームを変更します。細かい編集時は拡大、全体を
    俯瞰したい時は縮小。
  ● AI チャット
    AI との会話から、タイムラインの確認や編集を行えます。起動には
    claude CLI が必要です。PATH に無い場合は、コマンドプロンプトで
    npm i -g @anthropic-ai/claude-code を実行してインストールしてください。
  ● スチルを保存 / ワイプ比較 (オン/オフ) / スチルギャラリー
    「スチルを保存」で現在のフレームを PNG としてスチルギャラリーへ保存します。
    ギャラリーでスチルをダブルクリックし「ワイプ比較」を ON にすると、プレビューが
    保存スチルと現在フレームの分割表示になります (境界位置はギャラリーで調整)。
    プレビュー専用で、書き出しには影響しません。
  ● テーマ変更
    Dark / Light / Midnight / Ocean の 4 種から選択できます。
  ● ツールバーのツールチップを表示
  ● ツールバーをアイコンのみ表示
  ● メディアプール Dock のレーティングとフィルタ
    素材を右クリックすると 名前を変更… / お気に入り / 却下 / 星 (なし〜★5) / エクスプローラーで表示 が
    使えます (お気に入りと却下は排他)。上部のフィルタで すべて / お気に入り / 却下を除く / 未使用
    (タイムラインとネストシーケンスのどこにも置かれていない素材) に絞り込め、検索欄と組み合わせられます。
    レーティングはプロジェクトに保存されます。名前変更は表示名だけでファイルパスは変わりません。


--------------------------------------------------------------------------------
  2-4. トラック メニュー
--------------------------------------------------------------------------------

  ● ビデオトラックを追加
    V1, V2, V3... と複数の映像トラックを重ねられます。上のトラックが
    下のトラックを覆います。PiP や合成に使います。
  ● オーディオトラックを追加
    BGM、ナレーション、効果音などをそれぞれ別トラックで扱えます。
  ● トラックヘッダの右クリック: 名前を変更… / 色
    トラック左端のヘッダを右クリックすると、トラック名 (空欄で V1 / A1 の既定名に戻る)
    と色 (なし / 赤 / オレンジ / 黄 / 緑 / シアン / 青 / 紫 / ピンク) を設定できます。
    ヘッダのラベルと色ストライプに反映され、プロジェクトに保存されます。名前と色の
    変更は Ctrl+Z 1 回で戻ります。MCP の set_track_property からも同じ設定ができます。


--------------------------------------------------------------------------------
  2-5. 挿入 メニュー
--------------------------------------------------------------------------------

  ● テキスト / テロップ追加 (T)
    新しいテキストオーバーレイをクリップに追加。
  ● テキスト管理 (Ctrl+T)
    既存テキストオーバーレイの一覧を確認・編集。
  ● 字幕をインポート (SRT/VTT)
    外部の字幕ファイルを読み込んでテキストオーバーレイとして適用。
  ● テキストテンプレートを保存
    よく使うスタイルをテンプレート化。
  ● トランジションを追加
    クリップ間にフェード、ワイプなどのトランジションを挿入 (45 種)。
    「モーフカット」はオプティカルフローで前後のショットを変形しながらつなぎ、
    同じ人物のジャンプカットを目立たなくします。トランジションはプレビューだけ
    でなく書き出しにも同じ合成で反映されます。
    ワイプ / バーンドア / アイリス / クロックワイプでは「ソフトネス」(0〜100%)、「境界線の幅」(px)、
    「境界線の色」で境界をぼかしたり色付きの帯を付けたりできます (他の種類ではグレーアウト。
    既定値なら従来と同じ絵。プリセットにも保存されます)。
  ● 画像 / 静止画を追加
    PNG / JPEG などを配置。
  ● ピクチャー・イン・ピクチャー追加
    小窓で別クリップを重ねる PiP 機能。
  ● 平面レイヤー (単色)…
    色 (既定 白) と尺 (既定 5 秒、0.01〜86400 秒) を指定して、再生ヘッド位置の
    ビデオトラックに単色のクリップ「平面 #RRGGBB」を挿入します。背景・カラーマット・
    ルマキー / カラーキーの下敷きに使えます。再生ヘッドが既存クリップの内部なら
    そのクリップの直後に入ります (シェイプクリップと同じ規則)。Ctrl+Z 1 回で消えます。
  ● シェイプクリップ
    名前を付けて、再生ヘッド位置のビデオトラックにシェイプクリップを挿入します。
    図形はプレビューと書き出しで同じ描画経路を通り、プロジェクトに保存されます。
    クリップ右クリックの「シェイプモディファイア…」で Repeater / Trim Paths を設定できます。


--------------------------------------------------------------------------------
  2-6. オーディオ メニュー
--------------------------------------------------------------------------------

  ● 音量を設定
    選択クリップの音量を 0% (ミュート) ～ 200% (増幅) で指定。
  ● BGM / 音声ファイルを追加
    別の音声トラックに BGM を乗せます。
  ● ミュート切替 (M) / ソロ切替
    A1 トラックを一時的に消す / そのトラックだけ聞く。
  ● イコライザー
    プリセット (ボーカル強調・低音強調・ラジオ風など) で音質を調整。
  ● オーディオエフェクト
    リバーブ、コンプレッサー、ノーマライズ、フェードイン/アウト、
    バスブースト、ボイスエンハンスを適用。
  ● EQ パネル… / コンプレッサー / リミッター… / リバーブ… / ノイズリダクション…
    音声トラックごとの 4 バンド EQ / コンプレッサー / リバーブ / ノイズ除去です。
    ※ Wave 5 から、これらのトラック効果は書き出しにも反映されます (欠陥修正)。
    これまではプレビュー再生にだけ効き、書き出したファイルには掛かっていませんでした。
    再生と同じ順序・ヘッドルームで処理されるので、書き出しの音がプレビューと一致します。
    トラック効果を有効にしているプロジェクトは、書き出し音声が以前のバージョンと変わります。
  ● VST / AUプラグイン
    外部プラグインを読み込んでエフェクトチェーンに追加。


--------------------------------------------------------------------------------
  2-7. マーカー メニュー
--------------------------------------------------------------------------------

  ● 再生ヘッドにマーカー追加 (Ctrl+M)
    現在の位置にマーカー。種類は Standard / Chapter / Todo / Note。
  ● 全マーカーを表示
    マーカーの一覧を確認。
  ● YouTubeチャプターをエクスポート
    Chapter 種別のマーカーから YouTube の説明欄用チャプターテキストを
    生成します。


--------------------------------------------------------------------------------
  2-8. エフェクト メニュー
--------------------------------------------------------------------------------

  ● 色補正 / グレーディング (Ctrl+G)
    カラーグレーディング パネルには Lift/Gamma/Gain に加えて
    「Log ホイール (Shadow / Midtone / Highlight)」があり、暗部・中間・明部の
    Log レンジだけを個別に色付けできます (各 -1.0〜1.0、既定 0 = 無変化)。
    「カラーワーパー (色相 × 彩度)」は色相環上の 36 個のノード (色相 12 × 彩度 3) を
    ドラッグして、その付近の色相 (±60°) と彩度 (0〜2 倍) を変形します。ダブルクリックで
    そのノードをリセット、右クリック「すべてリセット」で全解除。既定では無変化です。
    HSL セカンダリ / Lift・Gamma・Gain / Log ホイール / カラーワーパーの各セクションには
    「キーフレーム追加」ボタンがあり、再生ヘッド位置の値をキーフレームとして記録して
    時間変化させられます (1 回の追加 = Ctrl+Z 1 回)。プレビューと書き出しの両方に効きます。
    GPU シェーダーで高速に色を調整。プレビューにリアルタイム反映。
  ● ビデオエフェクト (Ctrl+Shift+F)
    ブラー / シャープ / モザイクなどの映像エフェクト。
    ディストーション分類に「レンズ歪み補正」(径方向２次 / ４次、拡大率、中心Ｘ/Ｙ。プレビューと
    書き出しが同じ式) と「ローリングシャッター補正」(走査時間 / 走査方向 / 強度。前フレームとの
    オプティカルフローで、パン中に斜めに倒れた縦線を立てます) があります。
    Wave 5 で次の 9 種が加わりました (いずれも CPU 処理で、プレビューと書き出しが同じ絵になります):
      ・反転 (Flip/Flop) [ディストーション]: 方向 0=水平 / 1=垂直 / 2=両方。2 回掛けると元に戻ります。
      ・ワープ: ウェーブ / リップル / 球面化 / 魚眼 / ピンチ [ディストーション]: 振幅 (px) / 周波数 / 位相、
        半径 (短辺比)、量 (球面化は -1〜1、他は 0〜1)。量 0 なら無変化。
      ・ルマキー / カラーキー [カラー]: ルマキーは 下限しきい値 / 上限しきい値 (既定 0〜0.3) / ソフトネス、
        カラーキーは キーカラー (既定 緑) / 許容度 / ソフトネス。抜けた部分は透明になり、下のトラックが
        透けて書き出しにも反映されます。後ろに置いた効果で透明部分が失われるので、キーヤーはスタックの
        最後に置いてください (ライブラリのタグにも表示されます)。
      ・カメラ Log → Rec.709 [カラー]: 入力 0=S-Log3 / 1=LogC3 EI800 / 2=V-Log / 3=Cineon、露出オフセット (stop)、
        出力 0=ガンマ 2.4 / 1=リニア / 2=Rec.709 OETF。Log 収録素材を通常のコントラストに戻します。
  ● プラグインエフェクト
    自作・サードパーティ製プラグインを適用。
  ● LUT適用 (.cube)
    Film 風 LUT を適用して色味を変えられます。
  ● LUT管理
    登録済み LUT 一覧を確認。
  ● エフェクトプリセット適用 (Ctrl+P)
    事前に作ったエフェクトの組み合わせを 1 クリックで適用。
  ● 現在設定をプリセットに保存
    使い回したい色補正 + エフェクトの組合わせを保存。
  ● プリセット管理
    保存済みプリセットの一覧と削除。
  ● キーフレーム編集 (Ctrl+K)
    色補正値を時間経過でアニメーションさせます。
  ● オーディオをキーフレームに変換… (エフェクトコントロール パネル > Presets ボタン)
    音源 (リンク音声が既定。同時刻の音声クリップも選べます) の音量の包絡線を、対象プロパティ
    (不透明度 / スケール / 回転 / 位置 X / 位置 Y) のキーフレームに書き込みます。最小値・最大値、
    フレームレート (既定はプロジェクト fps)、平滑化 (ms、既定 50)、しきい値 (0〜1) を指定できます。
    音に合わせて拡大・点滅する演出が作れます。「変換」1 回 = Ctrl+Z 1 回。
    エクスプレッションでは audioLevel() (0〜1) / audioLevel(秒) でリンク音声の音量を直接参照できます
    (リンク音声が無いクリップでは 0)。
  ● GPUシェーダーエフェクト
    GLSL シェーダーによる高度な映像加工。
  ● GPUシェーダー管理
    シェーダーライブラリを確認。


--------------------------------------------------------------------------------
  2-9. 再生 メニュー
--------------------------------------------------------------------------------

  ● J / K / L 速度コントロール
    - J: 逆再生 / 速度を下げる
    - K: 再生 / 一時停止
    - L: 順再生 / 速度を上げる
    L を連打するたびに 2x, 4x, 8x と速度が上がります。
  ● イン点をマーク (I) / アウト点をマーク (O)
    再生範囲や書き出し範囲を指定します。


--------------------------------------------------------------------------------
  2-10. ツール メニュー (AI・自動編集)
--------------------------------------------------------------------------------

  ● 無音検出
    音声の無音区間を自動検出。
  ● 自動ジャンプカット
    無音区間をまとめて削除する "ジェットカット" を実行。
  ● シーン変化検出
    映像のシーン切り替え位置を自動検出。

  ● 手ブレ補正
    ハンドヘルド動画を 2-pass で安定化。

  ● スピードランプ (可変速)
    時間経過で速度を変える (例: 1x → 2x に加速)。

  ● モーショントラッキング
    指定領域を追跡し、オーバーレイを追従させます。

  ● 音声ノイズ除去 / 映像ノイズ除去
    ホワイトノイズやフィルムグレインを除去。

  ● 字幕自動生成 (Whisper)
    外部エンジン whisper-cli (whisper.cpp) で音声から字幕を自動生成します。
    設定 → 環境変数 → PATH → 既知のインストール先の順に自動検出し、見つからない
    場合は入手案内と「実行ファイルを指定…」ボタンが出ます (指定したパスは保存)。
    字幕翻訳ダイアログではプロバイダと API キーを保存でき、「このキーを保存」を外すと
    キーは保存されません。

  ● AI自動ハイライト
    映像のダイジェスト動画を自動生成します。

  ● 画面録画を開始 / 停止
    画面キャプチャ機能。

  ● プロキシモード切替 / プロキシ生成
    4K / 8K 動画を軽量な低解像度プロキシに置き換えて編集を軽くします。

  ● レンダーキュー (Ctrl+Shift+R)
    複数のエクスポートをキューに入れて一括実行。

  ● ネットワークレンダー
    LAN 内の他のマシンを使って分散レンダリング。

  ● Pythonスクリプトコンソール (Ctrl+Shift+P)
    Python スクリプトでプロジェクトを操作できます。

  ● マルチカメラセットアップ / 切替
    複数カメラ素材を同期してカメラ切替編集ができます。
    音声相関による自動同期は [ファイル] → [マルチカメラ...] の「音声で同期」を使います。
    このダイアログの同期も音声の相関で実際にオフセットを推定し、「N 本中 M 本を同期しました
    (音声なし K 本)」と結果を表示します (以前は同期せずオフセット 0 のままでした)。

  ● プラナートラッカー…
    平面 (壁・看板・画面など) の 4 隅を指定して追跡します。追跡後の「3D カメラを解析」で、
    平面の動きからカメラのパン / チルト / ロール / ドリーを推定し、プロジェクトの 3D カメラに
    キーフレームとして適用します (真の透視投影が自動で ON)。信頼度の低いフレームは補間され、
    適用直後なら Ctrl+Z で元に戻せます。平面シーン前提です。
  ● MCP サーバ
    LLM からエディタのタイムラインを操作するための localhost サーバです。
    [ツール] → [MCP サーバ] → [MCP サーバを有効にする] で起動します。
    起動後の [接続情報...] で、Claude Code や Codex CLI から接続するための
    mcp.json の内容を確認・コピーできます。サーバはこの PC の 127.0.0.1
    だけで待ち受けます。接続に使うトークンは他人に渡さないでください。


--------------------------------------------------------------------------------
  2-11. コンポジション メニュー (After Effects 風機能)
--------------------------------------------------------------------------------

  ● シェイプレイヤー追加
    長方形 / 楕円 / 星形 / ポリゴンなどを配置。
  ● パーティクルエフェクト追加
    雪・火花・煙などのプリセット。
  ● テキストアニメーション追加
    タイプライター / フェード / スライドなどのテキストアニメ。
  ● トランスフォームキーフレーム編集
    位置・スケール・回転・不透明度を時間軸でアニメ。
  ● カメラモーション...
    プロジェクト全体の 3D カメラ (位置・注視点・焦点距離 (px)・ロール) とドリー / パン / 周回 /
    手ぶれのプリセットを設定します。「真の透視投影 (回転・注視点・ロールを反映)」を ON に
    すると 3D レイヤーの回転・カメラの向き・ロールが本来の透視で描かれ、プレビューと書き出しの
    両方に効きます。既定 OFF で、OFF のときは従来と同じ描画です。
  ● ダイナミックズーム…
    開始枠と終了枠 (またはズームイン/アウト・パンのプリセット) を指定して、
    位置・スケールのキーフレームを一度に作成する Ken Burns 風の機能です。
    枠は常にキャンバスのアスペクト比に固定されます (高さを指定しても無視)。
  ● マスク追加
    矩形 / 楕円 / ポリゴン マスクで一部だけを表示。
  ● ワープ / 歪みエフェクト
    メッシュワープ / パペットピン / バルジ / ピンチなど。
    「ワープ / 歪みエフェクト…」では 種類 (ワープ: ウェーブ / リップル / 球面化 / 魚眼 / ピンチ) と
    最初のパラメータ (振幅や量) を指定して、選択中の映像クリップに追加します (Ctrl+Z 1 回)。
    残りのパラメータはエフェクトコントロール パネルで調整します。
  ● エクスプレッション
    プロパティを式で制御 (例: wiggle(2, 10))。
  ● 選択をプリコンポーズ
    選択したクリップをひとつのコンポジションにまとめます。


--------------------------------------------------------------------------------
  2-12. クリップの右クリックメニュー
--------------------------------------------------------------------------------

  タイムライン上のクリップを右クリックすると、カット/コピー/削除などと
  合わせて次の項目が使えます (映像・音声クリップ共通)。

  ● 置き換え
    メディアプールで選択中の素材へ、位置とトリムを保ったまま差し替えます。
    [編集] → [クリップをメディアプールの素材で置き換え] と同じ機能です。

  ● ラベルカラー
    なし / 赤 / オレンジ / 黄 / 緑 / シアン / 青 / 紫 / ピンク の 9 項目
    (8 色 + なし) から選び、クリップ本体と下端バーの色分けができます。
    複数選択して一括変更も可能。プロジェクト保存で保持されます。

  映像クリップのみ:

  ● パスに沿って自動回転 (チェック)
    位置キーフレームで作ったモーションパスの進行方向へクリップを自動回転させます。
    既存の回転値・回転キーフレームはオフセットとして加算されます。既定は OFF。

  ● シェイプモディファイア…
    シェイプクリップに「リピーター」(コピー数・移動・回転・拡大率・最後のコピーの
    不透明度) と「パスのトリミング」(開始・終了・オフセット) を設定します。
    無効のままなら描画は従来と同一です。

  ● 効果を焼き込んで差し替え…
    クリップの効果・変形を新しいメディア (H.264 MP4 / ProRes MOV) に書き出し、そのファイルに
    差し替えます。ハンドル秒で前後の余白を残せます。リンクした音声クリップも同時に焼き込まれます。
    重ね合わせトランジション付きやクロマキー付きのクリップは焼き込めません。

  ● 元のクリップに戻す
    焼き込んで差し替えたクリップを、効果付きの元のクリップに戻します (Ctrl+Z 1 回でも戻ります)。

  音声クリップのみ:

  ● 音声トランジション > クロスフェード (コンスタントパワー)… / フェードイン… / フェードアウト…
    継ぎ目や先頭・末尾に等パワーのフェードを明示的に付けます (0.1〜5.0 秒、既定 0.5)。
    クロスフェードは隣接クリップがあるときだけ選べ、前後のクリップが実際に重なって鳴ります
    (Center / Start / End at Cut で重なり位置を選択。余白が足りないと短縮されます)。
    プレビューと書き出しの両方に効きます。

  ● ダイアログレベラー…
    会話の短時間ラウドネスを解析し、目標 LUFS (既定 -18) へ平準化する音量エンベロープを
    生成します。無音区間は持ち上げません。既にエンベロープがある場合は上書き確認が出ます。

  ● ミュージックリミックス…
    BGM をビート境界で組み替えて、指定した目標尺に自動で合わせます。先頭と末尾は元のまま、
    継ぎ目にはコンスタントパワーのクロスフェードが付きます。ビートが 2 個未満だと適用できません。

  ● ノイズプリントを取得 (イン点〜アウト点) / ノイズプリントで除去…
    クリップ内にイン点・アウト点を打ってノイズだけの区間を採取し、「ノイズプリントで除去…」で
    除去量と下限 (dB) を指定してクリップ全体からそのノイズをスペクトル減算します。
    結果は別の .wav に保存して差し替えるので、Ctrl+Z 1 回で元の音源に戻ります。

================================================================================
  4. よくある操作の手順
================================================================================

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q1. 動画をカットして不要な部分を削除したい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. [開く] で動画をタイムラインに配置
   2. タイムライン下部のシークバーで不要部分の開始位置へ
   3. S キー (または [分割] ボタン) でカット
   4. 不要部分の終了位置へ移動し、再度 S キーでカット
   5. 中央の不要クリップを選択して Delete
   6. Shift + Delete なら後ろのクリップが前に詰まる (リップル削除)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q2. テロップ (字幕) を入れたい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. テロップを入れたい位置へ再生ヘッドを移動
   2. クリップを選択
   3. T キー (または [テキスト] ボタン) を押す
   4. ダイアログで文字・フォント・色・アウトライン・位置を設定
   5. OK を押すとクリップに紐づいたテロップとして登録

   既に作った字幕ファイル (.srt / .vtt) があれば
   [挿入] → [字幕をインポート] で一括登録できます。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q3. 色調補正をしたい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. 対象クリップを選択
   2. Ctrl + G (または [色補正] ボタン)
   3. スライダーで 明るさ・コントラスト・彩度・色温度 などを調整
     - プレビューには GPU シェーダーでリアルタイム反映されます
   4. OK を押すとそのクリップに色補正設定が保存されます


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q4. 動画を書き出したい (エクスポート)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. タイムラインに編集内容が揃っている事を確認
   2. Ctrl + E (または [出力] ボタン)
   3. ダイアログでコーデック・ビットレート・出力先を設定
      - YouTube アップロード向けなら H.264 / 10 Mbps 程度が一般的
      - 高画質保存なら H.265 / 20 Mbps 以上
   4. エクスポート実行。進捗はプログレスバーで確認
   5. キャンセルも途中で可能


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q5. 長い動画の中から無音部分を自動で削除したい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. 対象クリップを選択
   2. [ツール] → [自動ジャンプカット]
   3. 確認ダイアログで Yes
   4. 無音区間が自動検出されてカットポイントが生成されます
   5. 必要に応じて手動で S キーで分割 → 削除


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q6. J / K / L でプロ風の再生コントロールをしたい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   プロの編集ソフト (Premiere Pro / Final Cut など) と同じ操作感です。

   - K:       再生 / 一時停止
   - L:       順方向再生 (連打で 2x → 4x → 8x → 16x)
   - J:       逆方向再生 (連打で -2x → -4x → ...)
   - L → K:   停止
   - J → K:   停止
   - I:       イン点マーク (選択範囲の始まり)
   - O:       アウト点マーク (選択範囲の終わり)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q7. 動画にマーカーを付けて YouTube チャプターを作りたい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. 章の開始位置に再生ヘッドを移動
   2. Ctrl + M でマーカー追加
   3. 名前を入力、種類で [Chapter] を選択
   4. 必要な数だけ繰り返す
   5. [マーカー] → [YouTube チャプターをエクスポート] で
      YouTube 説明欄用のテキストを出力

      例:
        00:00 イントロ
        02:30 本題
        10:15 まとめ


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q8. 動画の一部をゆっくり再生 (スローモーション) にしたい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   方法 A: クリップ全体の速度を変える
     1. 対象クリップを選択
     2. [編集] → [再生速度を設定]
     3. 0.5x (半分速度) などを入力

   方法 B: 速度を徐々に変える (スピードランプ)
     1. 対象クリップを選択
     2. [ツール] → [スピードランプ]
     3. 開始速度・終了速度・イージングを設定


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q9. プロジェクトを保存して後で再開したい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. Ctrl + S でプロジェクトを保存 (.veditor 形式)
   2. 次回: [ファイル] → [プロジェクトを開く] で読み込む
   3. 自動バックアップは 2 分おきに ~/.veditor/autosave/ 配下へ保存されます
      クラッシュした場合は次回起動時に復旧ダイアログが出ます


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q10. ドラッグ & ドロップで動画を追加したい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   ウィンドウに MP4 / MKV / MOV / WebM / FLV / PNG / JPG / WAV / MP3 / AAC
   をドラッグ & ドロップで直接追加できます。
   プロジェクトファイル (.veditor) もドロップで開けます。


================================================================================
  付録: トラブルシューティング
================================================================================

  ● 起動時に復旧ダイアログが出る
    前回異常終了した時の自動保存ファイルがあるためです。
    必要なら Yes で復旧、不要なら No で無視して新規作業に進めます。

  ● 動画が落ちる・フリーズする
    対応コーデックでないか、プロキシが必要な 4K/8K 素材の可能性。
    [ツール] → [プロキシ生成] で軽量版を作ってから編集してください。

  ● ログファイル
    クラッシュ時のログは以下に保存されます:
      C:\Users\<ユーザー名>\.veditor\logs\veditor_YYYYMMDD_HHMMSS.log
    スタックトレース付きで記録されるので、バグ報告に添付してください。

  ● 自動保存ファイル
    C:\Users\<ユーザー名>\.veditor\autosave\
    最大 5 世代まで残ります。

  ● プロキシファイル
    C:\Users\<ユーザー名>\.veditor\proxies\
