================================================================================
  2. メニューバー
================================================================================

--------------------------------------------------------------------------------
  2-1. ファイル メニュー
--------------------------------------------------------------------------------

  ● 新規プロジェクト (Ctrl+N)
    新しいプロジェクトを作成します。最初に解像度とフレームレートを決めます。

  ● ファイルを開く (Ctrl+O)
    動画ファイルを直接読み込み、タイムラインに追加します。

  ● 最近使ったファイル
    過去に開いた動画・プロジェクトの一覧から選んで再度開けます。

  ● プロジェクトを開く (Ctrl+Shift+O)
    .veditor プロジェクトファイルを開きます。

  ● プロジェクトを保存 (Ctrl+S)
    現在のプロジェクトを上書き保存します。

  ● 名前を付けて保存 (Ctrl+Shift+S)
    別名で保存します。

  ● 保存版と比較…
    保存済みの .veditor ファイルを選ぶと、現在のタイムラインとの構造差分 (追加 / 削除 / 移動 /
    トリム / プロパティ変更 / 効果変更 / トランジション変更 / トラック設定変更) を一覧します。
    行をダブルクリックすると該当クリップを選択して再生ヘッドが移動します (削除済みは移動不可)。
    微小な数値差は同一扱いです。MCP では compare_project が同じ比較を返します。

  ● マルチカメラ...
    複数カメラの素材をアングルとして登録し、「音声で同期」ボタンで音声の相関から
    アングル間のオフセットを自動推定します (基準は最初のアングル)。推定値は各行の
    ms 欄に表示され、手で微調整できます。適用するとマルチカム EDL に反映されます。
  ● プロジェクトを収集 (Collect Files)...
    プロジェクトが参照する素材 (映像・音声・画像・LUT・パーティクル設定・ネストした
    シーケンス) を 1 つのフォルダへ集めます。対象の列挙は「メディアの再リンク」と
    同じ経路なので、収集漏れがありません。
  ● EDL を読み込み…
    CMX3600 の EDL ファイルをプロジェクトの FPS で新規シーケンスへ読み込みます。カット・
    ディゾルブを再現し、見つからない素材はオフラインのまま読み込みが続きます。完了ダイアログに
    解決済み / オフライン / 警告の件数が出ます。MCP の import_edl と同じ機能です。
    Wave 9 から、素材ファイルが見つかり、長さの probe が正の値を返したイベントは、その長さを素材長として取り込まれます
    (見つからない / probe に失敗したときは従来どおり使っている範囲まで)。取り込んだクリップの右端を伸ばせるのは、
    probe 値が使っている範囲の終わりより長いときだけです (従来は使っている範囲で止まりました)。
    EDL のディゾルブでは、長さが正のディゾルブなら、素材の有無に関係なく、取り込み直後の送り側クリップの後ろ側 (trail) に、少なくともディゾルブ長 ×
    速度ぶんのハンドルが確保されて常に正になるため (0 フレームのディゾルブはハンドルが 0 になり得て、trail は正になりません)、トランジション区間の描画が変わります。送り側クリップは、そのハンドル分だけは
    常に右端を伸ばせます。ハンドルを超えて素材の長さまで伸びるのは、素材が見つかり probe が正の値を返し、その値が
    ハンドル込みの長さより長いときだけです。EDL はソースのスタート
    タイムコードを差し引かない既存の制限があります。
  ● 外部ツール取り込みハブ(&I)… の「FCPXML を読み込み…」
    Final Cut Pro の FCPXML を新規シーケンスへ読み込みます。spine 直下の asset-clip に加えて、
    アンカーの子要素として書かれた接続クリップ (Final Cut Pro の標準出力形式) も、親クリップを
    基準にした位置で lane に取り込みます (Wave 8 で対応。従来は読み飛ばして警告に積んでいました)。
    映像は lane 0 を先頭に番号の絶対値が小さい順に並べ、飛び番を詰めて 1 lane 1 トラックで取り込みます
    (Wave 13 からトラック数の上限はありません。Wave 8 〜 12 は映像・音声とも最大 2 トラックで、超えた lane は
    「2 トラックの上限により lane N を読み飛ばしました。」の警告で読み飛ばしていました)。音声だけの asset-clip は
    音声トラックに配置されます (従来は映像トラック側に置かれていました)。クリップを持たない lane は
    トラック枠を使いません。値が不正なクリップは警告つきで読み飛ばされ、asset-clip はあったのに取り込めるクリップが
    1 つも無いときだけエラーになります (asset-clip が 0 本の spine は、下の Wave 9 の説明のとおりエラーではなく警告つきの空のシーケンスです)。
    Wave 13 から、transition・複合クリップ (ref-clip)・マルチカム (mc-clip)・clip / sync-clip も取り込みます
    (下の Wave 13 の段落)。MCP の import_fcpxml と同じ機能です。
    Wave 9 から、gap の子として置かれた接続クリップは gap の位置を基準に取り込まれ、親より前に
    始まる接続クリップ (J カットの音声など) も取り込まれます。タイムライン 0 秒より前に一部だけ出る分は
    切り詰めて警告「接続クリップをタイムライン 0 で切り詰めました: <名前> / <ref>」が出ます。0 秒より前に全体が出る
    クリップ (切り詰めると長さが 0) は取り込まれず、「クリップの値が不正です (接続位置): <名前> / <ref>」で読み飛ばされます。接続クリップを持つ親クリップの時刻範囲が不正 (duration が 0、または offset / start の計算が不正) な場合、その親は「lane N の時刻範囲が不正なクリップを読み飛ばしました: <名前> / <ref>」で、その接続クリップは「親クリップが不正なため接続クリップを読み飛ばしました: <名前> / <ref>」で、警告つきで読み飛ばされます (従来は取り込まれることがありました)。クリップが 1 本も無い spine はエラーではなく空のシーケンスと
    警告「読み込めるクリップがありません。」になります。子を持たない spine の gap について
    「未対応の要素を読み飛ばしました: gap (行 N)」の警告は出なくなりました。<asset> に長さがある
    FCPXML では、取り込んだクリップの右端を素材の終わりまで伸ばせます (asset の start が 0 でなくても同じ。
    長さが無い FCPXML は従来どおり使用範囲まで)。
    Wave 13 から次の要素を取り込みます (対応表は README の「FCPXML 読み込みの対応表」と同じ)。実際の Final Cut Pro
    が書き出した .fcpxml での確認は、どの行もまだ行っていません。
     ・lane (接続クリップ): トラック数の上限なし。lane は 0 を先頭に番号の絶対値が小さい順に並べ、飛び番を詰めて 1
       lane 1 トラック。音声専用の素材は音声トラック (US-1204)。 [自作 fixture で確認]
     ・clip / sync-clip: コンテナを平坦化して、子の映像・音声を取り込む (US-1204)。 [自作 fixture で確認]
     ・音声付き asset-clip: `<asset>` が `hasAudio="1"` で音声専用でなく、`srcEnable` が video 以外の asset-clip は、
       映像と同じ offset / start / duration の音声クリップを同じ番号の A lane に作り、V + リンク A の対 (リンクグ
       ループ) として取り込む。接続クリップなら映像側と同じ接続先に付く。`<clip>` に明示の音声の子があるときは複製
       しない (US-1308)。 [自作 fixture で確認]
     ・接続クリップ: 主ストーリーラインへの接続 (anchorUid / anchorOffsetSec、負のオフセット = J カット) として取り
       込む。音声のみの spine クリップに付いた子は接続を解除し、警告「主ストーリーラインが音声クリップのため接続を解
       除しました: <名前>」 (US-1204)。 [自作 fixture で確認]
     ・gap に接続された子: gap の位置を基準に取り込むが、接続にはしない (FCP では接続になる。既知の差)。 [自作
       fixture で確認]
     ・負の lane の映像: V に置き、警告「lane N の映像は FCP では主ストーリーラインの下に合成されます。V<n> に置きま
       した。」 (合成順が FCP と逆になる。既知の差)。 [自作 fixture で確認]
     ・transition: 前後のクリップの両縁に CrossDissolve (Center)。前後が重なる形は重なりの中点で詰める。ハンドル不足
       は長さを縮めて警告。先頭・末尾は FadeIn / FadeOut。名前が Cross Dissolve 以外のものは CrossDissolve に置き換
       えて警告 (US-1205)。前後のクリップが取り込み後に同じトラックで接していない場合 (別トラックに置かれた、間が空いて
       いる、または重なりを詰めた結果が別トラックに分かれた場合) は transition を付けず、「未対応の要素を読み飛ばしまし
       た: transition (行 N)」の警告を出す。 [実機未確認 (transition の時刻配置は自作 fixture のみ)]
     ・複合クリップ (media/sequence + ref-clip): ネストシーケンス (sequenceRefId) として取り込む。入れ子は深さ 8 ま
       で、循環参照は警告して読み飛ばす。MCP import_fcpxml の応答 sequences に入れ子の ID が入る。取り込み直後の
       undo 1 回で取り込み前の状態 (入れ子シーケンスを含む) に戻る (US-1206)。 [自作 fixture で確認]
     ・マルチカム (media/multicam + mc-clip): 有効アングル (mc-source の srcEnable が video / all。無ければ最初のアン
       グルを使い警告) の spine を、mc-clip の区間で切り出して平坦化する。有効な音声アングルが別なら音声トラックの接続
       クリップ。使わなかったアングルは警告に列挙 (US-1207)。`srcEnable="audio"` の source は音声アングルとして取り込
       み、mc-clip の `audioStart` / `audioDuration` を音声クリップの開始と長さに使う。lane が 0 以外の mc-clip (接続
       されたマルチカム) は読み飛ばさず、mc-clip を囲む spine の親クリップへの接続クリップとして取り込む (別アングルの
       音声は映像の切り出しに接続)。アングルが mc-clip の範囲より短いときは末尾を空け、警告「mc-clip <名前> のアングル
       <アングル> が範囲より <秒> 秒短いため末尾を空けました」を出す (US-1309)。mc-angle 内の transition は「mc-angle
       内の transition を読み飛ばしました (N 件)」の警告で読み飛ばす。 [実機未確認 (mc-clip の属性は自作 fixture の
       み。`audioStart` / `audioDuration` は DTD の記憶に基づく)]
     ・コンテナ (clip / sync-clip / mc-clip) の範囲: コンテナの `duration` を枠の終端に使い、超える子は切り詰めて
       警告「コンテナの長さを超えるクリップを切り詰めました: <名前> / <ref>」、枠の外に完全に出た子は警告「コンテ
       ナの範囲外のクリップを読み飛ばしました: <名前> / <ref>」で読み飛ばす。接続されたコンテナが 0 秒より前に出る
       分は 0 秒で切り詰め (警告「接続クリップをタイムライン 0 で切り詰めました」)、子は切り詰め後の枠で配置する
       (US-1310)。 [自作 fixture で確認]
     ・上記以外の要素: 従来どおり、警告「未対応の要素を読み飛ばしました: <要素名> (行 N)」で読み飛ばす。
  ● メディアの再リンク (自動)
    プロジェクトを開いたときに見つからない素材があると、再リンクダイアログが出ます。
    フォルダを指定すると同名ファイルを一括で再リンクし、リンクした音声やネストした
    シーケンスの参照もまとめて更新します。Ctrl+Z 1 回で戻せます。
    ファイルメニューの「メディアを再リンク…」からは、プロジェクトを開いたあとでもいつでも同じダイアログを開けます。
    オフラインの映像 / 音声クリップにはタイムライン上でバッジが付きます (幅 40px 以下のクリップはバッジを省き、名前末
    尾の (オフライン) だけ。Wave 15)。
  ● エクスポート (Ctrl+E)
    動画ファイルとして書き出します (コーデック・ビットレート指定)。
    「レート制御」で ビットレート / 品質 (CRF) を選べます。CRF は H.264 / H.265 / VP9 が 0〜51 (既定 23)、
    AV1 が 0〜63 (既定 30) で、小さいほど高画質・大容量です (ProRes では選べません)。AV1 の CRF で
    ハードウェアエンコーダが使えない環境ではソフトウェア (libsvtav1) に自動で切り替わります。
    「音声のみ (映像なし)」にチェックすると m4a (AAC) / wav (PCM 16bit) / mp3 の音声ファイルだけを
    書き出します。中間ミックスは PCM なので損失圧縮は最後の 1 回だけです。
    レンダーキューに入れてもレート制御 / CRF / 音声のみ の設定は保持されます。
    Wave 9 から、書き出し設定の音声ビットレート (kbps) は、音声を AAC へ再エンコードする経路
    (中間ファイルを作る経路) に反映されます (従来は常に 192 kbps でした。192 のときの出力は
    変わりません)。素材の音声をそのままコピーする経路では元のビットレートのままです。
    書き出しダイアログ / モバイル書き出し / バッチ書き出し / 自動ラウドネス経由で作られる音声の中間ファイルは、書き出しが
    完了・失敗・キャンセルされたあとに削除されます。使用中で消せないファイルは残され、あとのジョブの終了時に再試行して削除されます
    (それまでの間はファイルが残ることがあります)。

  ● エクスポート: ユーザープリセットの保存と削除
    書き出しダイアログで解像度・コーデック・レート制御などを決めたあと
    「現在の設定をプリセットに保存…」を押すと、名前を付けて自分用のプリセットとして
    残せます。プリセット一覧では区切り線の下にユーザープリセットが並び、選ぶと全項目が
    復元されます。組み込みと同じ名前は使えません (別名を求められます)。同名のユーザー
    プリセットには上書き確認が出ます。「プリセットを削除」はユーザープリセットを選んで
    いるときだけ有効です。MCP の export_video でも preset に名前を渡せます。
    Wave 8 から、字幕の選択、連番静止画の設定 5 項目 (連番にするか・フォルダ・ファイル名の
    パターン・桁数・開始番号)、「ラウドネスを自動で合わせる」の ON/OFF と目標 LUFS の計 8 項目も
    保存・復元されます (従来はこれらが保存されず、プリセットを選んでも前の値が残っていました)。
    連番静止画のプリセットを選ぶと「種類」とフォルダも復元され、動画と連番を切り替えても
    それぞれ使えるファイル / フォルダが保たれます。MCP の export_video に preset を渡したとき、
    プリセットに保存された連番の出力先へ書き出しが振り替えられることはありません。
    ★挙動変更 (Wave 10): MCP の export_video で preset に「ラウドネスを自動で合わせる」が ON の
    ユーザープリセットを渡し、autoLoudness を省略すると、そのプリセットの自動ラウドネスと目標
    LUFS に従って書き出し音声が正規化されます (Wave 9 までは MCP では正規化されませんでした)。
    ON のプリセットを preset= で使っている既存の MCP 呼び出しは、引数を足さなくても出力音量が
    変わります。従来どおりにするには autoLoudness=false を明示してください。詳細は下の
    「エクスポート: ラウドネスを自動で合わせる」を参照。

  ● エクスポート: アルファチャンネルを保持 (ProRes 4444 / VP9)
    コーデックに ProRes 4444・ProRes 4444 XQ または VP9 を選ぶと
    「アルファチャンネルを保持 (ProRes 4444 / VP9)」が押せるようになります (既定はオフ)。
    オンにすると、キーヤーやシェイプなどで透明になっている部分が透明のまま書き出され、
    他のソフトに重ねられます。対応していないコーデック (H.264 など) に切り替えるとチェックは
    自動的に外れます。オフのときの書き出しは従来どおり黒で塗り潰した不透明の絵です。

  ● エクスポート: 連番静止画 (PNG / TIFF / EXR)
    書き出しダイアログの「種類」で「連番静止画 (PNG / TIFF / EXR)」を選ぶと、音声を含めず
    指定フォルダへ 1 フレームずつ連番のファイル名で保存します。フォーマット (PNG / TIFF) と
    連番の桁数を指定できます。
    Wave 13 から、フォーマットに EXR を選べます。同梱の avcodec に exr エンコーダがあるときだけ選べ、無い環境では
    EXR は選択肢に出ません。表示参照 (既定) のほか、チェック「EXR をシーンリニアで書き出す」 (既定 OFF) でシーンリニ
    アで書けます。この設定はユーザープリセットにも保存されます。PNG / TIFF の書き出しは変わりません (US-1212 /
    US-1213)。

  ● エクスポート: メタデータ
    「メタデータ」欄のタイトル・作成者・著作権・コメントに入力すると、入力した項目だけが
    書き出しファイルへメタデータとして埋め込まれます (空欄の項目は書き込まれません)。
    MCP の export_video では metadata で同じ 4 項目を指定できます。

  ● エクスポート: 字幕
    「なし」「焼き込み（従来の設定を引き継ぐ）」「mov_text 埋め込み」「両方」から選べます。
    mov_text 埋め込みは字幕を独立したストリームとして MP4 / MOV に追加します (焼き込まれず、
    プレイヤー側の字幕トラックとして切り替えられます)。MP4 / MOV 以外のコンテナでは選べません。
    既定は「焼き込み」です。

  ● エクスポート: ラウドネスを自動で合わせる
    「配信 -14 LUFS」「放送 -23 LUFS」のプリセット、または「自由入力」で目標 LUFS を指定すると、
    書き出し後の音声を自動的に正規化します (既定はオフ)。無音・音声なし・測定失敗のときは
    適用ゲイン 0dB のまま書き出されます。
    自動ラウドネスが効くのは、通常の書き出し・モバイル書き出し・バッチエクスポートのキュー
    (ユーザープリセット経由。Wave 8 で対応、次項) と、Wave 10 から MCP の export_video です。
    RenderInPlace と、レンダーキューダイアログからの手動追加では効きません (設計)。
    ★挙動変更 (Wave 10) MCP の export_video: 任意引数 autoLoudness (真偽値) と targetLufs (数値、
    -70〜-1) が加わりました。解決順は「明示した引数 > preset で指定したユーザープリセットの値 >
    オフ (目標 LUFS は -14)」です。autoLoudness を省略すると指定プリセットの設定に従うため、
    自動ラウドネスが ON のユーザープリセットを preset= で使う既存の MCP 呼び出しは、引数を足さなくても
    音量が正規化されるようになり、出力音量が変わります (従来どおりにするには autoLoudness=false を
    明示)。引数の省略 + プリセット無し (またはオフのプリセット) は従来と同じです。targetLufs だけを
    指定して autoLoudness が解決後にオフのときは、値の検証だけを行い正規化はしません。
    autoLoudness=true の明示と audioOnly=true の併用はエラーです。audioOnly=true は、ON のプリセットを
    指定して引数を省略した場合も自動ラウドネスを行いません (Wave 10 の挙動変更。従来は測定していました。
    GUI の音声のみ書き出しは変わりません)。測定は Wave 12 から画面の処理とは別のスレッドで実行され、autoLoudness=true の
    準備中も get_export_status は応答します (status は queued)。
    測定に失敗した場合 (無音・音声なしなど) は正規化をスキップして
    0 dB のゲインで書き出しを続け、ジョブは完了します。ジョブが failed になるのは、音声ミックスを
    作れない・変換できないときだけです。
    audioBitrate (kbps、既定 192) は、192 以外のとき書き出し前に作る音声ミックスのビットレートにも
    反映されます。
    Wave 9 から、形式を連番静止画 (PNG / TIFF) にすると、音声を書き出さないため「ラウドネスを
    自動で合わせる」と配下の項目 (プリセット・目標 LUFS) は無効になり、動画形式に戻すと有効に戻ります
    (バッチ設定ダイアログには適用されません)。
    ★挙動変更 (Wave 11) 通常 / モバイル書き出しで自動ラウドネスが ON のとき、 (1) 音声の再生シーケンスが空 (音声クリッ
    プが無い) のプロジェクトは、出力の音声が V1 素材の音声ではなく無音になります。 (2) 音声ミックス (無音ミックスを含
    む) の作成に失敗したときは、正規化なしで書き出さずにジョブを拒否します (ジョブはキューに入らず、通常は「Export
    Failed」、モバイルは「モバイル書き出し失敗」ダイアログにエラーが表示されます。MCP の export_video では failed と
    エラーで分かります)。バッチと MCP の出力は変わらず、自動ラウドネスが OFF の書き出しも変わりません。
    ★挙動変更 (Wave 12) 通常 / モバイル書き出しで自動ラウドネスが ON のとき、音声のミックスと測定は画面の処理とは別
      のスレッドで実行され、「音声を準備しています…」の進捗ダイアログ (キャンセル可) が出ます。キャンセルするとジョ
      ブはキューに入りません。MCP の export_video (autoLoudness=true) も準備中に get_export_status が応答します。
    ★挙動変更 (Wave 12) V1 が空で上位のトラックに映像がある書き出しは、通常 / モバイル / MCP / バッチ (自動ラウドネス ON
      / OFF) のすべての入口で音声トラックが付きます (音声クリップが無ければ無音、あれば音声が混ざります)。
      (自動ラウドネス ON のバッチで音声クリップが無いタスクの扱いは README の制限事項を参照)。
      V1 にクリップがあるプロジェクトと、映像が 1 つも無いプロジェクトは変わりません。

  ● バッチエクスポート(&B)… (ツール(&T) メニュー)
    複数の書き出しをキュー (ウィンドウ「Batch Export Queue」) に積んでまとめて処理します。
    [ファイルを追加...] はプロジェクトファイルを、[現在のプロジェクトを追加] は開いている
    タイムラインを編集内容ごと追加します (Source 列で区別できます)。追加時の「Batch export
    settings」ダイアログの Preset で、組み込みの 1080p / 720p / 4K か、保存済みのユーザー
    プリセットを選びます。
    Wave 8 から、このダイアログに出るユーザープリセットはすべて、自動ラウドネスと目標 LUFS が
    タスクに載ります (組み込みは 1080p / 720p / 4K の 3 つだけで、大文字小文字を区別せず、前後の
    空白は無視して判定します。それ以外の名前は、書き出しダイアログのユーザープリセットと同じ名前でも
    前後に空白があっても、保存済みユーザープリセットとして扱われます)。ラウドネス設定はタスクを
    追加した時点で取り込まれるので、あとでプリセットを削除・変更しても、積み済みのタスクは
    変わりません。ラウドネス付きのタスクは通常の書き出しと同じ準備で正規化され、音声が無音・
    測定不能のときは理由つきで失敗し、一時ファイルは残りません。ラウドネスの無いタスクは、映像は
    従来と同じで、音声は現在のプロジェクトのタスクならタイムラインのミックスになります
    (下の Wave 9 の説明。Wave 8 までは V1 先頭クリップのソース音声でした)。
    ● 制限事項: 組み込み名 (1080p / 720p / 4K) と同名の保存済みユーザープリセットは Preset の
      一覧に出ず、組み込みが優先されます。保存済みユーザープリセットとして一度も解決できなかった
      名前のタスクは、ラウドネス無しで実行されます。
    Wave 9 から、現在のプロジェクト (開いているタイムライン) のタスクで自動ラウドネスが無い場合、
    出力の音声はタイムライン全体のミックス (複数トラック・トラック FX・ゲイン・フェード込み) に
    なります (従来は V1 先頭クリップのソース音声でした。映像は変わりません)。ただしタイムラインの長さが 0 より大きく
    音声の再生シーケンスが空でないときだけで、長さ 0 のとき、または音声トラックが無い / 音声を持つクリップが無いときは
    ミックスを作らず、従来どおり元ファイルの音声で書き出します (警告は出ません。V1 が空で上位トラックに映像があるときは
    無音のミックスになります (US-1109))。全トラックがミュートでも音声を持つ
    クリップがあれば、ミュート分を除いた無音のミックスで書き出されます (警告は出ません。通常書き出しと同じ)。ミックスは
    タスクを実行する時点のタイムラインから作られるため、キューに積んだあとの編集が反映されます
    (映像と同じ)。ミックスの作成に失敗したときは元ファイルの音声で書き出し、書き出しが成功した場合だけタスクの
    メッセージが「Export complete (タイムライン音声ミックスの作成に失敗したため元ファイル音声で書き出します: <原因>)」
    になります (書き出しが失敗した場合はエラーメッセージが優先され、警告は残りません)。自動ラウドネス付きのタスクは従来どおり、ラウドネス測定用のミックスが使われます。
    ● 制限事項: [ファイルを追加...] で追加した、現在のプロジェクト以外のファイルを指すタスクは、
      自動ラウドネスが OFF のときだけ、従来どおり元ファイルの音声 (V1 先頭クリップのソース音声) で書き出されます。
      自動ラウドネスが ON のときは測定できないため、「自動ラウドネス: 現在のプロジェクト以外のタスクでは測定できません」
      というエラーでタスクが失敗し、書き出されません。
    キューを保存する処理 (API。現在の画面にはキューを保存 / 読み込む操作はありません) は、ミックス用の
    一時音声ファイルではなく元のプロジェクトのパスを保存します (Wave 9)。画面から確認する手順はありません。
    Wave 16 から、保存済みプリセットとして解決できないプリセット名のタスクは失敗 (Failed) になり、出力は作られ
    ません (US-1510。下の「Wave 16」の注記を参照)。

  ● タイムコード焼き込み設定…
    プレビューと動画書き出しに表示するタイムコードの位置・書式を設定します。
    無効時は書き出しが従来と byte-identical になります。

  ● Remotion形式でエクスポート
    Remotion (React ベースの動画生成フレームワーク) のプロジェクト形式で
    出力します。Web 上で動的な動画を生成したい場合に便利です。

  ● 環境設定 > 書き出し完了を通知する (Wave 11 追加)
    チェックを入れる (既定はオフ) と、通常 / モバイル / MCP の書き出しがすべて終わったとき、ステータスバーに「書
    き出しが完了しました (N 件、失敗 M 件)」を 10 秒間表示し、ウィンドウを点滅させて音を鳴らします。
    ★挙動変更 (Wave 12) レンダーキューダイアログ (「レンダーキュー...」) は専用のキューではなくメインの共有キューを
      使います。ダイアログから追加したジョブも通知の件数に入り、プロジェクトの ACES が有効なときは ACES 付きで書き出
      されます。書き出しの進捗は job の uuid で絞られ、進捗ダイアログのキャンセルはそのジョブだけを止めます。

  ● 終了 (Ctrl+Q)
    アプリケーションを終了します。

  2-2. 編集 メニュー
--------------------------------------------------------------------------------

  ● 元に戻す (Ctrl+Z) / やり直す (Ctrl+Shift+Z)
  ● クリップをコピー (Ctrl+C) / 貼り付け (Ctrl+V)
  ● 複製 (Ctrl+D)
    選択したクリップをそれぞれの直後に複製します。リンクした映像・音声は一緒に
    複製され、新しいリンク番号が付きます。空きが足りなければトラック末尾に入ります。
    Ctrl+Z 1 回で戻ります。
  ● すべて選択 (Ctrl+A) / 再生ヘッド以降を選択 / 再生ヘッド以前を選択
    ロック中・非表示のトラックを除く全クリップ、または再生ヘッドより後ろ (前) の
    クリップをまとめて選択します (再生ヘッドにかかるクリップも含みます)。
  ● 再生ヘッドで分割 (S)
  ● 全トラックを再生ヘッドで分割 (Ctrl+Shift+K)
    再生ヘッド位置にある全トラックのクリップを一度に分割します (ブレードオール)。
    ロック中のトラックは対象外、リンクは維持されます。Ctrl+Z 1 回で戻ります。
    Wave 16 から、速度ランプ / タイムリマップを持つクリップの分割は両片が素材区間と長さを保ち、wiggle と式は
    両片に乗ります (書き出しの違いは「Wave 16 の変更」を参照。US-1501 / US-1504 / US-1505)
  ● クリップを削除 (Delete) / リップル削除 (Shift+Delete)
  ● リフト (ギャップを残して削除)
    選択クリップを削除し、後続のクリップは動かしません (空きが残ります)。
  ● 1フレーム左へ移動 (Alt+←) / 1フレーム右へ移動 (Alt+→)
  ● 10フレーム左へ移動 (Alt+Shift+←) / 10フレーム右へ移動 (Alt+Shift+→)
    選択クリップをフレーム単位 (1/fps 秒) で動かします (ナッジ)。隣のクリップに
    ぶつかる場合はステータスバーに「指定位置へ移動できません。候補: N 秒」、
    0 秒より前には行かず「ナッジ位置を N 秒に調整しました。」と出ます。
    リンクしたクリップは一緒に動き、ロック中のトラックは動きません。1 回の
    ナッジ = Ctrl+Z 1 回。
  ● すべてのギャップを詰める
    全トラック (ロック中を除く) で同時に空いている区間だけをまとめて詰めます。
    1 つのトラックだけが空いている区間は、他のトラックがずれてしまうので詰めません。
    Ctrl+Z 1 回で戻ります。
  ● スナップ切替 (N)
    クリップ境界にピッタリ吸着するかどうかを切り替えます。細かい調整を
    したい時はオフ、綺麗に並べたい時はオンにします。
  ● 再生速度を設定
    選択クリップの再生速度を 0.25x ～ 4.0x の間で指定します。
  ● マッチフレーム (F)
    再生ヘッド位置のクリップを、対応するソース時刻でソースモニターに
    開きます。速度変更・逆再生・タイムリマップを反映した時刻になります。
  ● クリップをメディアプールの素材で置き換え
    選んだクリップの位置とトリムを保ったまま、メディアプールで選択中の
    素材へ差し替えます。新素材が短い場合は警告が出ます。クリップ右クリック
    メニューの「置き換え」からも同じ操作ができます。
  ● 逆再生
    選んだクリップを後ろから再生します (チェックで ON/OFF)。リンクした
    映像・音声クリップにも同時に適用され、速度変更と併用できます。
  ● キーボードショートカット (Ctrl+Alt+K)
    ショートカットのカスタマイズダイアログを開きます。


  ● タイムコードへジャンプ… (Ctrl+Shift+J)
    「時:分:秒:フレーム」「分:秒」「秒」のいずれかで位置を入力して移動します。
    先頭に + や - を付けると現在位置からの相対移動になります。シーケンスの
    範囲を超える値は端に丸められます。

  ● クリップの先頭 / 末尾を再生ヘッドへ移動
    選択クリップの先頭 (または末尾) が再生ヘッド位置に来るように動かします。
    リンクした音声も一緒に動きます。隣のクリップとぶつかる場合は置ける位置まで
    寄せます。Ctrl+Z 1 回で元の位置に戻ります。

  ● 同じラベルのクリップを選択
    選択中のクリップと同じラベルカラーのクリップをまとめて選びます。
    選択操作なので「元に戻す」には積まれません。

  ● リンク選択
    チェックを入れている間は、映像クリップを選ぶとリンクした音声も一緒に
    選ばれます (既定はオン)。外すと映像だけを個別に扱えます。設定は次回
    起動時も保持されます。
    リンクしたクリップ (映像と音声のペア) の端をマウスでドラッグしてトリムしたときの動きも
    変わりました (Wave 8)。端ドラッグはリンク先も一緒にトリムされ、Alt を押しながら
    ドラッグすると掴んだクリップだけをトリムします。詳しくは下の「グループ化 / グループ解除」
    を参照してください。

  ● 範囲ドラッグ選択 (マーキー)
    タイムラインの空いている場所からドラッグすると矩形が出て、重なった
    クリップがまとめて選ばれます。Shift を押しながらドラッグすると今の選択に
    追加します。ロック中・非表示のトラックは対象外です。

  ● クリップを有効にする (クリップ右クリック)
    チェックを外すと、そのクリップをプレビュー・書き出しの両方から除外します。無効な
    クリップはタイムライン上で斜線ハッチングのグレー表示になります。Null Object クリップと
    ロック中のトラックでは操作できません。MCP の set_clip_enabled と同じ機能です。

  ● グループ化 / グループ解除
    トラックをまたいで選んだ複数クリップをまとめ、以後は選択・移動・トリム・削除が連動します。
    「グループ解除」で個別に戻ります。対象にならない選択のときはグレーアウトし、理由が
    ステータスバーに出ます。MCP の group_clips / ungroup_clips と同じ機能です。
  ● クリップをトラック間でドラッグ移動  ★挙動変更 (Wave 11)
    クリップを別のトラックへドラッグして落とすと、リンク相手 (映像と音声のペア) の移動と、必要になったトラックの
    新設を含めて Ctrl+Z 1 回で元に戻ります (元に戻すの表示は「クリップをトラック間移動」)。
    リンクした音声トラックへ落としたときも、リンク相手の映像クリップの roto / 親子付け / マットは移動後のクリッ
    プに付いたまま動きます。主クリップのクロストラック drag と範囲リップル (文字起こし編集) でも、トラックマット
    は元のクリップに付いたまま動きます。

    roto / 親子付け / トラックマットは、クリップの uid を優先して見分けます (Wave 12)。同じクリップを貼り付けた複製
    も、それぞれ自分の roto / 親子付け / マットを持ち続け、手前のクリップをまたぐ並べ替えでも外れません。

  ● 新しいトラックへ drop (Wave 12 追加)
    タイムライン末尾にある「新トラックの帯」 (V トラックの下 / A トラックの下の細い行) へクリップを落とすと、トラックが
    新設されてクリップがそこへ移ります (Ctrl+Z 1 回で元に戻ります。元に戻すの表示は「クリップを新しいトラックへ移動」)。
    リンクした映像と音声は、同じ番号の相方トラック (無ければ新設) へ付いて動きます。
    ストーリーライン ON のときは、メディアビンやファイルの drop も帯で受け、トラックを新設して取り込みます (V の帯は
    映像ファイル、A の帯は音声を持つファイルを音声のみとして。Wave 15)。

  ● 主ストーリーラインと接続クリップ (Wave 13 追加)
    V2 以上の映像クリップと音声クリップを、V1 のクリップに「接続」できます。編集メニューまたはクリップの右クリックの
    「主ストーリーラインに接続」で接続し、「接続を解除」で外します (新規ショートカットはありません。どちらも 1 操作
    = Ctrl+Z 1 回)。接続したクリップは接続先 (アンカー) の移動・トリム・速度変更に追従し、タイムラインに接続線とバッ
    ジが描かれます。MCP の connect_clip / disconnect_clip でも同じ操作ができ、get_timeline のクリップに anchorUid /
    anchorOffsetSec が付きます (US-1201 / US-1202)。
    編集メニューの「主ストーリーライン (マグネティック)」 (チェック式。コマンド ID は timeline.storyline_mode) は既定
    OFF で、プロジェクトに保存されます (undo の対象外)。ON の間は V1 だけが insert / ripple 削除 (リンク相手も一緒に消
    える) / ripple トリム (Q / W) / 隙間詰めの対象になり、V1 に隙間が残りません (Wave 14 で V1 への media drop は drop
    位置への insert になり、マウスの端トリムと nudge も ripple します。例外として + 方向の nudge は、開けた前の空きが
    後続の storyline insert や移動で詰まるまで残ります。US-1304 / US-1305)。V1 のリンクした音声は V1 に追従します。V2
    以上や音声トラックへ素材・クリップを drop すると、開始位置が重なる V1 のクリップにその場で接続されます (重なる V1
    クリップが無ければ接続せずに置きます)。OFF のときの動作は Wave 12 までと同じです (US-1203)。
     ・接続はリンクグループ単位です (対になる音声も同じ接続先に付きます)。接続先は V1 のクリップだけで、V1 のクリッ
       プ自身は接続できません。
     ・接続先の開始・イン / アウト点・速度・反転・ランプ・リマップが変わったとき、線形な接続先 (速度一定・非反転・ランプ
       とリマップ無し) では、接続クリップは同じ素材フレームに付いたまま動きます。非線形な接続先では、接続先の開始からの
       位置を保ちます (FCP との既知の差)。接続先の前後にはみ出してもかまいません。追従先に置き場所が無いときは、元の位置
       (空いていなければ自トラックの末尾) に置いて接続を解除し、ステータスバーに「「<名前>」の接続を解除しました (退避先
       のトラックがありません)」を出します。
     ・接続先を消すのは明示的な削除 (Delete / Shift+Delete / MCP の delete_clip など Timeline の削除操作) だけで、そ
       のとき接続クリップも連動して削除されます。MultiCam 適用・新規シーケンス化・読込など、それ以外の理由で接続先が
       消えたときは、接続クリップを残して接続を解除し、ステータスバーに「「<名前>」の接続を解除しました (<理由>)」の
       警告を出します。ロック中のトラックの接続クリップと、削除される区間の外にはみ出した接続クリップも、削除せず解
       除 + 警告です。
     ・接続がある間は、V1 トラックの削除と、V1 を起点または終点にするトラックの移動が拒否されます。ロック中のトラッ
       クの接続は動かさず、解除 + 警告です。
     ・接続先の分割では、接続クリップが位置を変えずに左右の片へ振り分けられます (接続クリップ自身を分割したときは右
       片も同じ接続先に付きます)。cut → paste、複製、新規シーケンス化は接続を複製しません。bake (映像・音声) は接続
       を保ちます。無音カットで除去した区間にある接続クリップは、削除せず解除して残ります。MultiCam を適用すると接続
       は解除されます。
     ・FCPXML から取り込んだ接続クリップは、モードが OFF でも接続として取り込まれ、同じ規則で追従します。
     ・主ストーリーラインの ON では、V1 へのメディアファイルの drop が drop 位置への insert になり、V1 の端トリム (リ
       ンクした音声も開始位置固定) と nudge も ripple します (Wave 14。US-1304 / US-1305)。nudge で + 方向に開けた
       前の空きは、後続の storyline insert や移動で詰まるまで V1 に残ります。V1 と他のトラックにまたがる選択の
       nudge は拒否されます (選択した V1 クリップのリンク相手は対象外)。ブレードと MCP の編集ツールは ON でも ripple
       しません (従来どおり)。OFF のときの W と MCP の trim_clip は、下流のクリップがトリム量 d だけ動きます (従来は
       2d 動く欠陥の修正)。
    保存形式 (.veditor。PROJECT_FORMAT_VERSION は 2 のまま): 任意キーが 3 つ加わりました: クリップの anchorUid と
    anchorOffsetSec (接続されているときだけ)、プロジェクトの storylineMode (ON のときだけ)。旧ファイルはそのまま読め、
    旧ビルドでも読めますが、旧ビルドで再保存すると接続とモードは失われます。読込時に接続先の uid が見つからない接続
    は、解除 + 警告です。プロジェクトの比較 (compare) は anchorUid / anchorOffsetSec を無視します。

  ● マット設定・バス割当の undo (Wave 12)  ★挙動変更
    マットの設定や、バスパネルのバス割当・バスの gain・mute・solo・名前のように自前の undo 点を積まない編集は、直前の
    undo 点に吸収されます (吸収した編集は redo を捨てます)。マットを設定した直後に別の編集を元に戻しても、マットは消えま
    せん。ミキサーのストリップのコンボでバスを割り当てる操作は自前の undo 点 (「トラックのバスを変更」、Ctrl+Z 1 回) に
    なります。

  ● リンクしたクリップの端ドラッグ (AV ペア / グループ)  ★挙動変更 (Wave 8)
    リンクしたクリップ (映像と音声のペア、グループ化したクリップ) の端をマウスでドラッグして
    トリムすると、既定でリンク先も一緒にトリムされます (従来は掴んだクリップだけがトリムされました)。
    Alt を押しながらドラッグすると、掴んだクリップだけをトリムします。速度が違うクリップは
    それぞれの速度に換算され、リンク先が素材の長さや隣のクリップに当たると、全員がいちばん
    厳しい限界で止まります (隣のクリップは押し出しません)。リンク先のトラックがロック中のときは、
    リンクしたトリムは受け付けられません。1 回のドラッグは Ctrl+Z 1 回で全員が元に戻ります。
    マウスの端ドラッグ以外のトリムメニューのトリム (リップル / ロール / スリップ / スライドなど) は従来どおり、選んだクリップと同じ linkGroup を持つ他のトラックのクリップ (V1 ↔ A1 の AV ペアなど) に同じトリムを適用し、相手側で失敗したら全体を元に戻します (「リンクしたクリップをトリムできません: ...」)。同じトラック上のグループメンバーには連動しません。

  ● キーフレームのコピー & ペースト (グラフエディタ > 「キーフレーム編集」)
    選択したキーフレームを「選択キーフレームをコピー」でコピーし、別のパラメータや別の
    クリップで「再生ヘッド位置にキーフレームを貼り付け」を実行すると、再生ヘッド位置を基準に
    シフトして貼り付きます。補間方式・ベジェハンドル・空間タンジェントも保持されます。
  ● グラフエディタ: 色相 / ガンマ / ハイライト / シャドウのキーフレーム  (Wave 8)
    グラフエディタのプロパティに grade.hue / grade.gamma / grade.highlights / grade.shadows の
    4 項目が増え、キーフレームを打てるようになりました。プレビューと書き出しの両方がキーの値に
    従います (キーを打たない色補正は従来と同じ絵です)。


--------------------------------------------------------------------------------
  2-3. 表示 メニュー
--------------------------------------------------------------------------------

  ● 拡大 / 縮小 (Ctrl+= / Ctrl+-)
    タイムラインのズームを変更します。細かい編集時は拡大、全体を
    俯瞰したい時は縮小。
  ● AI チャット
    AI との会話から、タイムラインの確認や編集を行えます。起動には
    claude CLI が必要です。PATH に無い場合は、コマンドプロンプトで
    npm i -g @anthropic-ai/claude-code を実行してインストールしてください。
  ● スチルを保存 / ワイプ比較 (オン/オフ) / スチルギャラリー
    「スチルを保存」で現在のフレームを PNG としてスチルギャラリーへ保存します。
    ギャラリーでスチルをダブルクリックし「ワイプ比較」を ON にすると、プレビューが
    保存スチルと現在フレームの分割表示になります (境界位置はギャラリーで調整)。
    プレビュー専用で、書き出しには影響しません。
  ● テーマ変更
    Dark / Light / Midnight / Ocean の 4 種から選択できます。
  ● ツールバーのツールチップを表示
  ● ツールバーをアイコンのみ表示
  ● メディアプール Dock のレーティングとフィルタ
    素材を右クリックすると 名前を変更… / お気に入り / 却下 / 星 (なし〜★5) / エクスプローラーで表示 が
    使えます (お気に入りと却下は排他)。上部のフィルタで すべて / お気に入り / 却下を除く / 未使用
    (タイムラインとネストシーケンスのどこにも置かれていない素材) に絞り込め、検索欄と組み合わせられます。
    この「未使用」判定は LUT ファイル・画像オーバーレイ・パーティクル設定からの参照も「使用中」
    とみなすようになったため、それらだけで使われている素材は「未使用」に出なくなりました。
    レーティングはプロジェクトに保存されます。名前変更は表示名だけでファイルパスは変わりません。


  ● シーケンス全体を表示 / 選択範囲にズーム
    「シーケンス全体を表示」は全クリップが画面に収まる倍率にします。
    「選択範囲にズーム」は選択中のクリップが画面幅いっぱいになるまで拡大します
    (何も選んでいないときは選べません)。

  ● メディアプールのサムネイルを表示
    メディアプールの素材一覧にサムネイルを出します (既定はオン)。素材の上で
    マウスを左右に動かすと、その位置に応じたフレームが 8 段階で切り替わるので、
    取り込まずに中身を確認できます。オフにするとサムネイルの読み込みも止まります。

  ● クリップのサムネイルを表示
    タイムラインの映像クリップの中に、内容のサムネイルを並べて表示します
    (既定はオフ)。メディアプールと同じ画像を使い回すので、同じ素材を二重に
    読み込むことはありません。

  ● シーケンス一覧
    シーケンスの一覧ドックを出します (既定は非表示)。今開いているシーケンスが
    太字になり、ダブルクリックで切り替えられます。下部の「新規シーケンス」で追加、
    右クリックの「名前を変更…」で改名できます。追加と改名は Ctrl+Z 1 回で戻ります。

  ● タイムラインのスキミング
    有効にすると、映像クリップの上でマウスを左右に動かした位置のフレームがプレビューに
    出ます (再生ヘッドは動きません)。クリップ範囲外にマウスが出ると再生ヘッド位置の絵に
    戻ります。既定はオフ。

  ● オーディオミキサー
    トラックごとのフェーダーとメーターを並べたミキサー Dock を表示します (既定は非表示)。
    トラックの追加・削除・並べ替えに追従します。フェーダーやノーマライズで設定したゲインは、
    そのトラックに FX を一切掛けていなくても書き出し音声に反映されます (以前は再生時だけ
    音量が変わり、書き出しでは元に戻る不整合がありました)。
    Wave 12 から各ストリップにパンのスライダ (中央にスナップ) とバス割当のコンボ (「マスター」とバス名) が付きます。
    操作はそれぞれ「トラックのパンを変更」「トラックのバスを変更」として元に戻せます。トラックの gain と pan はプロ
    ジェクトに保存され (trackMix。すべて既定値のときは書きません)、再生と書き出しに反映されます。★挙動変更: gain を 1.0
    以外にして保存したプロジェクトは、再読込後も gain が保たれ、再生と書き出しが変わります。クリップ pan が 0 以外のクリ
    ップは、トラック FX が無い書き出しでも pan が掛かります。

  ● スペクトラムアナライザ (Wave 11 追加)
    master バスの音声を 48 kHz の 2048 点 FFT で表示する Dock です (既定は非表示)。表示だけで、音声は変わりませ
    ん。Dock を出している間だけ PCM タップが有効になり、閉じると何もコピーしません。
    PCM タップは再生処理の 1 か所でまとめて書かれ、デコーダ停止中 (シーク直後や開始直後) の無音も通常の音声と同じ
    箇所で書かれます。一時停止中は書かれません (US-1116)。
    Wave 12 から、Dock 上部のコンボで表示する信号を選べます (「マスター」または A<n>。トラックは FX 後・フェーダー前
    )。信号が無いときは表示が 12 dB/s で床まで下がります。

  ● オーディオ バス (表示メニュー。AUX センドは Wave 12 追加)
    バスパネルの「センド」表で、選んだバスへの AUX センドを音声トラックごとに設定します (列: トラック / レベル (dB) 
    / プリフェーダー)。レベルが -60 dB 以下のトラックはセンド無しです。1 回の変更は Ctrl+Z 1 回で戻ります (元に戻す
    の表示は「AUX センドを変更」)。再生と書き出しのミックスに反映され、センドはバスのエフェクトを通さずに加算されま
    す。書き出しは、バスの割当・gain・mute・solo にも従います (★挙動変更: これらを使ったプロジェクトの書き出しが変わ
    ります)。

  メディアプールの素材を右クリックすると、レーティングやフィルタに加えて次の項目も使えます:

  ● キーワードを編集…
    複数選択した素材に共通のキーワードを 1 行ずつ追加・削除します。追加したキーワードごとに
    「キーワード」セクション配下に仮想ビンが自動でできます。

  ● このクリップから新規シーケンス
    その素材だけを含む新しいシーケンスを作りアクティブにします。映像 (+音声) の素材は V1
    (+A1) の先頭、音声のみの素材は A1 の先頭に配置します。

  メディアプール左側のビンツリー (ビン一覧) を右クリックすると、次の項目が使えます:

  ● 未使用素材を削除…
    タイムラインとネストしたシーケンスのどこにも使われていない素材をまとめて削除します。
    LUT ファイル・画像オーバーレイ・パーティクル設定が参照している素材は「使用中」として
    残ります。未使用素材が無ければ「未使用素材はありません。」と出ます。


--------------------------------------------------------------------------------
  2-4. トラック メニュー
--------------------------------------------------------------------------------

  ● ビデオトラックを追加
    V1, V2, V3... と複数の映像トラックを重ねられます。上のトラックが
    下のトラックを覆います。PiP や合成に使います。
  ● オーディオトラックを追加
    BGM、ナレーション、効果音などをそれぞれ別トラックで扱えます。
  ● トラックヘッダの右クリック: 名前を変更… / 色
    トラック左端のヘッダを右クリックすると、トラック名 (空欄で V1 / A1 の既定名に戻る)
    と色 (なし / 赤 / オレンジ / 黄 / 緑 / シアン / 青 / 紫 / ピンク) を設定できます。
    ヘッダのラベルと色ストライプに反映され、プロジェクトに保存されます。名前と色の
    変更は Ctrl+Z 1 回で戻ります。MCP の set_track_property からも同じ設定ができます。


  ● 選択トラックを削除 / 上へ移動 / 下へ移動
    選択中のトラックを削除したり、並び順を入れ替えたりします。トラックヘッダの
    右クリックからも同じ操作ができます。クリップが載っているトラックを削除すると
    きは「N 個のクリップも削除されます。トラックを削除しますか？」と確認が出ます
    (既定は「いいえ」)。最後の 1 本とロック中のトラックは削除できず、メニューが
    無効になります。並べ替えは端では無効です。
    削除・移動をすると、トラックマット / 親子付け / 調整レイヤー / ミキサー /
    バス送りの参照も一緒に付け替わり、Ctrl+Z 1 回で本数も中身も元に戻ります。
    MCP の add_track / remove_track / move_track からも同じ操作ができます。
    なお、ソロ / ミュート / 非表示の再生フラグはもともと「元に戻す」の対象外なので、
    トラック操作を取り消してもその時点の値のまま維持されます。

  ● 字幕エディタ… (分割 / 結合は Wave 11 追加)
    字幕を追加・編集し、SRT/VTT の取り込み・書き出しや音声認識ができるダイアログです。
    一覧で 1 行を選び「分割位置 (ms)」を指定して「分割」を押すと、その時刻で 2 つの字幕に分かれます (単語の時刻
    がある字幕は単語ごとに振り分け、無ければ文字数の比で分けます。話者は両方に複製されます)。
    隣り合う同じ話者の 2 行を選んで「結合」を押すと 1 つになります (テキストは半角スペース 1 つで連結)。範囲外の
    位置、隣り合わない行、話者の違う行では押せません。
  ● テキストテンプレートを保存
    よく使うスタイルをテンプレート化。
  ● トランジションを追加
    クリップ間にフェード、ワイプなどのトランジションを挿入 (45 種)。
    「モーフカット」はオプティカルフローで前後のショットを変形しながらつなぎ、
    同じ人物のジャンプカットを目立たなくします。トランジションはプレビューだけ
    でなく書き出しにも同じ合成で反映されます。
    ワイプ / バーンドア / アイリス / クロックワイプでは「ソフトネス」(0〜100%)、「境界線の幅」(px)、
    「境界線の色」で境界をぼかしたり色付きの帯を付けたりできます (他の種類ではグレーアウト。
    既定値なら従来と同じ絵。プリセットにも保存されます)。
  ● 画像 / 静止画を追加
    PNG / JPEG などを配置。
  ● ピクチャー・イン・ピクチャー追加
    小窓で別クリップを重ねる PiP 機能。
  ● 平面レイヤー (単色)…
    色 (既定 白) と尺 (既定 5 秒、0.01〜86400 秒) を指定して、再生ヘッド位置の
    ビデオトラックに単色のクリップ「平面 #RRGGBB」を挿入します。背景・カラーマット・
    ルマキー / カラーキーの下敷きに使えます。再生ヘッドが既存クリップの内部なら
    そのクリップの直後に入ります (シェイプクリップと同じ規則)。Ctrl+Z 1 回で消えます。
  ● シェイプクリップ
    名前を付けて、再生ヘッド位置のビデオトラックにシェイプクリップを挿入します。
    図形はプレビューと書き出しで同じ描画経路を通り、プロジェクトに保存されます。
    クリップ右クリックの「シェイプモディファイア…」で Repeater / Trim Paths / Round Corners / ZigZag / Wiggle Path (毎
    秒のウィグル数が 0 のあいだは静的) / Pucker & Bloat / Twist / Offset Path を設定できます。


--------------------------------------------------------------------------------
  2-6. オーディオ メニュー
--------------------------------------------------------------------------------

  ● 音量を設定
    選択クリップの音量を 0% (ミュート) ～ 200% (増幅) で指定。
  ● BGM / 音声ファイルを追加
    別の音声トラックに BGM を乗せます。
  ● ミュート切替 (M) / ソロ切替
    A1 トラックを一時的に消す / そのトラックだけ聞く。
  ● イコライザー
    プリセット (ボーカル強調・低音強調・ラジオ風など) で音質を調整。
  ● オーディオエフェクト
    リバーブ、コンプレッサー、ノーマライズ、フェードイン/アウト、
    バスブースト、ボイスエンハンスを適用。
  ● EQ パネル… / コンプレッサー / リミッター… / リバーブ… / ノイズリダクション…
    音声トラックごとの 4 バンド EQ / コンプレッサー / リバーブ / ノイズ除去です。
    ※ Wave 5 から、これらのトラック効果は書き出しにも反映されます (欠陥修正)。
    これまではプレビュー再生にだけ効き、書き出したファイルには掛かっていませんでした。
    再生と同じ順序・ヘッドルームで処理されるので、書き出しの音がプレビューと一致します。
    トラック効果を有効にしているプロジェクトは、書き出し音声が以前のバージョンと変わります。
    ★挙動変更 (Wave 10) undo: これらのパネルの操作が undo の対象になりました (ジェスチャ単位。
      スライダー / ダイヤルのドラッグ 1 回、またはホイール 1 ノッチが Ctrl+Z 1 回分。マスターは EQ と
      ディエッサーが対象。ディエッサーはスピンボックスの確定で 1 回。ディエッサーの試聴 (listen) と
      旧来のマスターコンプは対象外です)。
      (Wave 8 までは、パネルを開いたままプロジェクトを読み込む・新規作成する・トラックを増減すると
      コントロールが古い値のまま残り、次の操作でその古い値が書き戻されることがあり、パネルを
      開き直す必要がありました。Wave 9 で解消したため、開き直す必要はありません。下の「Dock の追従」を参照。)
    ★挙動変更 (Wave 9) Dock の追従: EQ / コンプレッサー / リバーブ / ノイズリダクションの Dock は、
    開いたままプロジェクトを読み込む・新規作成する・トラックを増減しても、ディエッサー Dock と
    同じく対象の一覧とコントロールの値が追従します。追従中の値が古い値としてミキサーへ書き戻される
    ことはありません。Dock の操作は Wave 9 までは undo に積まれませんでした (Wave 10 から対象)。
  ● ディエッサー...  ★挙動変更 (Wave 8)
    シビランス (サ行などの歯擦音) だけを検出して動的に抑制します。メニューを選ぶと、EQ /
    コンプレッサー / リバーブ / ノイズリダクションと同じ Dock パネル「ディエッサー」が右側に開きます
    (従来は「適用」「キャンセル」ボタン付きのモーダルダイアログでした。今は「適用」ボタンはありません)。
    「対象」(マスター / A1 ...) を選び、「有効」・「周波数」(1000〜16000 Hz)・「しきい値」(-60〜0 dB)・
    「レシオ」(1〜20:1)・「レンジ（最大減衰量）」(0〜24 dB)・「リッスン（検出帯域のみ）」を設定します。
    値を変えるとその場で再生音に反映されます。対象を切り替えても、各対象の編集値は保持されます。
    Dock を開いたままプロジェクトを読み込む・新規作成する・トラックを増減しても、対象の一覧と
    値が追従します (EQ / コンプレッサー / リバーブ / ノイズリダクションのパネルも同様に追従します。
    Wave 8 まではこれらのパネルは追従しませんでした)。Wave 10 からディエッサー Dock の操作も
    undo の対象です (スピンボックスの確定で 1 回。リッスン (listen) は対象外)。既定は無効です。
    トラック FX チェーンの一部としてプロジェクトに保存され、書き出しにも同じ設定が掛かります。
    ★挙動変更 (Wave 11) リッスン (listen) は、そのトラック自身に付いて動きます。トラックの削除 / 追加 / 移動とそ
    の undo / redo の前後でも、リッスンが別のトラックに移りません (欠陥修正)。

  ● VST / AUプラグイン
    外部プラグインを読み込んでエフェクトチェーンに追加。


  ● EQ パネルの「マスター」
    EQ パネル上部のトラック選択で「マスター」を選ぶと、すべてのトラックを
    ミックスした後段に掛かる EQ を設定できます (既定はオフで、スライダーを
    動かすと有効になります)。再生と書き出しの両方に同じ設定が掛かります。
    コンプレッサー / リバーブ / ノイズリダクションのパネルにはマスター行は
    ありません (マスターは EQ のみ)。
    トラック音声効果とマスター EQ はプロジェクトに保存され、開き直すと復元
    されます。別のプロジェクトを開いたり新規作成したりすると設定はクリアされます。

  ● Track EQ > A<n> > 4 バンド EQ へ移行 (Wave 11 追加)
    旧 3 バンドの EQ を、現行の 4 バンド トラック EQ へ移します。メニューで実行したときだけ移行し、プロジェクト
    の読込では変換しません。1 操作 = Ctrl+Z 1 回です (元に戻すの表示は「EQ を 4 バンドへ移行」)。表現できない設
    定のときはメッセージが出て、何も変わりません。

--------------------------------------------------------------------------------
  2-8. エフェクト メニュー
--------------------------------------------------------------------------------

  ● 色補正 / グレーディング (Ctrl+G)
    カラーグレーディング パネルには Lift/Gamma/Gain に加えて
    「Log ホイール (Shadow / Midtone / Highlight)」があり、暗部・中間・明部の
    Log レンジだけを個別に色付けできます (各 -1.0〜1.0、既定 0 = 無変化)。
    「カラーワーパー (色相 × 彩度)」は色相環上の 36 個のノード (色相 12 × 彩度 3) を
    ドラッグして、その付近の色相 (±60°) と彩度 (0〜2 倍) を変形します。ダブルクリックで
    そのノードをリセット、右クリック「すべてリセット」で全解除。既定では無変化です。
    HSL セカンダリ / Lift・Gamma・Gain / Log ホイール / カラーワーパーの各セクションには
    「キーフレーム追加」ボタンがあり、再生ヘッド位置の値をキーフレームとして記録して
    時間変化させられます (1 回の追加 = Ctrl+Z 1 回)。プレビューと書き出しの両方に効きます。
    GPU シェーダーで高速に色を調整。プレビューにリアルタイム反映。
  ● ビデオエフェクト (Ctrl+Shift+F)
    ブラー / シャープ / モザイクなどの映像エフェクト。
    ディストーション分類に「レンズ歪み補正」(径方向２次 / ４次、拡大率、中心Ｘ/Ｙ。プレビューと
    書き出しが同じ式) と「ローリングシャッター補正」(走査時間 / 走査方向 / 強度。前フレームとの
    オプティカルフローで、パン中に斜めに倒れた縦線を立てます) があります。
    Wave 5 で次の 9 種が加わりました (いずれも CPU 処理で、プレビューと書き出しが同じ絵になります):
      ・反転 (Flip/Flop) [ディストーション]: 方向 0=水平 / 1=垂直 / 2=両方。2 回掛けると元に戻ります。
      ・ワープ: ウェーブ / リップル / 球面化 / 魚眼 / ピンチ [ディストーション]: 振幅 (px) / 周波数 / 位相、
        半径 (短辺比)、量 (球面化は -1〜1、他は 0〜1)。量 0 なら無変化。
      ・ルマキー / カラーキー [カラー]: ルマキーは 下限しきい値 / 上限しきい値 (既定 0〜0.3) / ソフトネス、
        カラーキーは キーカラー (既定 緑) / 許容度 / ソフトネス。抜けた部分は透明になり、下のトラックが
        透けて書き出しにも反映されます。後ろに置いた効果で透明部分が失われるので、キーヤーはスタックの
        最後に置いてください (ライブラリのタグにも表示されます)。
      ・カメラ Log → Rec.709 [カラー]: 入力 0=S-Log3 / 1=LogC3 EI800 / 2=V-Log / 3=Cineon、露出オフセット (stop)、
        出力 0=ガンマ 2.4 / 1=リニア / 2=Rec.709 OETF。Log 収録素材を通常のコントラストに戻します。
  ● プラグインエフェクト
    自作・サードパーティ製プラグインを適用。
  ● LUT適用 (.cube)
    Film 風 LUT を適用して色味を変えられます。
  ● LUT管理
    登録済み LUT 一覧を確認。
  ● エフェクトプリセット適用 (Ctrl+P)
    事前に作ったエフェクトの組み合わせを 1 クリックで適用。
  ● 現在設定をプリセットに保存
    使い回したい色補正 + エフェクトの組合わせを保存。
  ● プリセット管理
    保存済みプリセットの一覧と削除。
  ● キーフレーム編集(&K)... (Ctrl+K)
    色補正値を時間経過でアニメーションさせます。
    Wave 8 から、このダイアログで打つ色補正のキー (grade.brightness / grade.contrast /
    grade.saturation / grade.exposure / grade.hue / grade.temperature / grade.gamma /
    grade.highlights / grade.shadows の 9 種) が実際に絵へ効きます。従来は colorCorrection.* という
    名前で保存されるだけで、プレビューにも書き出しにも効いていませんでした。以前のプロジェクトは
    読み込み時に grade.* へ自動移行されます (入れ子のシーケンスの中も対象)。同じ項目に旧名と
    新名の両方があるときは grade 側を残し、警告をログに出します。新しいキーのトラックは 0 では
    なくクリップの現在値から始まるので、最初のガンマのキーでクリップが真っ黒になることはありません。
    旧キーを持たないプロジェクトは、読み込みも保存も従来と変わりません。
  ● オーディオをキーフレームに変換… (エフェクトコントロール パネル > Presets ボタン)
    音源 (リンク音声が既定。同時刻の音声クリップも選べます) の音量の包絡線を、対象プロパティ
    (不透明度 / スケール / 回転 / 位置 X / 位置 Y) のキーフレームに書き込みます。最小値・最大値、
    フレームレート (既定はプロジェクト fps)、平滑化 (ms、既定 50)、しきい値 (0〜1) を指定できます。
    音に合わせて拡大・点滅する演出が作れます。「変換」1 回 = Ctrl+Z 1 回。
    エクスプレッションでは audioLevel() (0〜1) / audioLevel(秒) でリンク音声の音量を直接参照できます
    (リンク音声が無いクリップでは 0)。
  ● GPUシェーダーエフェクト
    GLSL シェーダーによる高度な映像加工。
  ● GPUシェーダー管理
    シェーダーライブラリを確認。


  ● LUT適用 (.cube)… / LUT強度 / LUT 解除
    選択中の映像クリップに LUT を適用します。プレビューだけでなく書き出しにも
    反映され、プロジェクトに保存されます (強度の変更と解除も同じ扱いです)。
    映像クリップを選んでいないときは「映像クリップを選択してください。」と表示され、
    何も変わりません。MCP の apply_lut と同じクリップ属性を操作します。

  ● このエフェクトにマスクを設定… (エフェクトコントロール パネルでエフェクトを右クリック)
    ベジェパス (3 点以上) で範囲を描き、フェザー (%) を指定すると、そのエフェクトだけを
    マスク内側に適用します (マスク外側は入力そのまま、他のエフェクトには影響しません)。
    ブラシで描いた結果は保存されません (3 点未満のパスと同様に既存のマスクを保持します)。

  ● オフセットホイール (カラーグレーディング パネル、Lift / Gamma / Gain の隣。パネル上の表示名は「オフセット」)
    プリンターライト相当のホイールです。Lift/Gamma/Gain とは独立して全体の明るさを底上げ・
    底下げします (赤・緑・青を個別の数値ボックスでも調整可)。「キーフレーム追加」で時間変化
    させられます。MCP の set_color_correction では offsetR/G/B (-2〜2) で設定できます。

  ● 放送セーフ / 色を残す (ビデオエフェクト… の「カラー」)
    「放送セーフ」は放送規格を超える輝度・彩度を範囲内に収めます。規格は
    Rec.709 リーガル と RGB 全域 から選べ、上限クロマも指定できます。
    「色を残す」は指定した色 (既定は赤) に近い部分だけ色を残し、他をモノクロに
    します。許容度で残す色の幅、彩度の減衰で背景の色の落とし具合を調整します。
    どちらも CPU で処理するため、プレビューと書き出しの絵が一致します。

--------------------------------------------------------------------------------
  2-10. ツール メニュー (AI・自動編集)
--------------------------------------------------------------------------------

  ● 無音検出
    音声の無音区間を自動検出。
  ● 自動ジャンプカット
    無音区間をまとめて削除する "ジェットカット" を実行。
  ● シーン変化検出
    映像のシーン切り替え位置を自動検出。

  ● 手ブレ補正
    ハンドヘルド動画を 2-pass で安定化。

  ● スピードランプ (可変速)
    時間経過で速度を変える (例: 1x → 2x に加速)。

  ● モーショントラッキング
    指定領域を追跡し、オーバーレイを追従させます。

  ● 音声ノイズ除去 / 映像ノイズ除去
    ホワイトノイズやフィルムグレインを除去。

  ● 字幕自動生成 (Whisper)
    外部エンジン whisper-cli (whisper.cpp) で音声から字幕を自動生成します。
    設定 → 環境変数 → PATH → 既知のインストール先の順に自動検出し、見つからない
    場合は入手案内と「実行ファイルを指定…」ボタンが出ます (指定したパスは保存)。
    字幕翻訳ダイアログではプロバイダと API キーを保存でき、「このキーを保存」を外すと
    キーは保存されません。

  ● AI自動ハイライト
    映像のダイジェスト動画を自動生成します。

  ● 画面録画を開始 / 停止
    画面キャプチャ機能。

  ● プロキシモード切替 / プロキシ生成
    4K / 8K 動画を軽量な低解像度プロキシに置き換えて編集を軽くします。

  ● レンダーキュー (Ctrl+Shift+R)
    複数のエクスポートをキューに入れて一括実行。
    ジョブを選んで「選択ジョブを中止」を押すと、そのジョブだけを止めます (待機中のジョブは一覧から削除、実行中のジョブ
    は中止)。「キュー全体を停止」は共有キュー全体 (MCP や通常書き出しのジョブを含む) を止めます。

  ● ネットワークレンダー
    LAN 内の他のマシンを使って分散レンダリング。

  ● Pythonスクリプトコンソール (Ctrl+Shift+P)
    Python スクリプトでプロジェクトを操作できます。

  ● マルチカメラセットアップ / 切替
    複数カメラ素材を同期してカメラ切替編集ができます。
    音声相関による自動同期は [ファイル] → [マルチカメラ...] の「音声で同期」を使います。
    このダイアログの同期も音声の相関で実際にオフセットを推定し、「N 本中 M 本を同期しました
    (音声なし K 本)」と結果を表示します (以前は同期せずオフセット 0 のままでした)。

  ● プラナートラッカー…
    平面 (壁・看板・画面など) の 4 隅を指定して追跡します。追跡後の「3D カメラを解析」で、
    平面の動きからカメラのパン / チルト / ロール / ドリーを推定し、プロジェクトの 3D カメラに
    キーフレームとして適用します (真の透視投影が自動で ON)。信頼度の低いフレームは補間され、
    適用直後なら Ctrl+Z で元に戻せます。平面シーン前提です。

  ● プラナートラッカー… の「特徴点トラッキング (3D)」
    平面に限らず使える多フレームのカメラ解析です。開始フレーム・終了フレーム (いずれも
    素材の先頭を 0 とした番号で指定。ダイアログを開くとクリップのトリム (inPoint/outPoint) に
    合わせて既定値が自動入力される。最大 60 フレームの窓にクランプ)・最大特徴点数を指定して
    「特徴点を追跡」を実行し、続けて「カメラを解析」を押すと、確認
    ダイアログなしでその場に KLT 追跡 → 姿勢の連結 → バンドル調整 (Schur 補元法。大規模な
    フレーム数・点数にも対応) の結果からカメラの位置・注視点のキーフレームが書き込まれます
    (適用時にクリップの inPoint・速度・逆再生を反映してタイムライン時刻へ変換するため、
    トリム・速度変更・逆再生は正しく反映されます)。誤差が許容範囲を超えるときは適用されず
    理由が表示されます。速度ランプ・タイムリマップ付きクリップには適用できません。
    デコードできない素材では「解析用フレームを読み込めませんでした。」と表示されます。
    適用は Ctrl+Z 1 回で戻せます。
    Wave 8 から、ダイアログを開いた直後のサマリは、フレームを読み込む前でも
    「投入: 読み込み待ち (期待 N フレーム) / 追跡済: ... / 平均信頼度: ...」と期待フレーム数を
    表示し (従来は「投入: 0」)、別のクリップで開き直したときに前のクリップのフレームや結果が
    残りません。特徴点の追跡中にダイアログを閉じてもアプリは落ちません (閉じてから 5 秒待っても
    終わらない追跡は切り離され、アプリ終了時には中断されます)。速度ランプ・タイムリマップ付きの
    クリップにはカメラ解析の結果を適用できません (「速度ランプまたはタイムリマップのあるクリップには
    適用できません。」と表示されます)。ランプを外した状態で解析してください。
  ● MCP サーバ
    LLM からエディタのタイムラインを操作するための localhost サーバです。
    [ツール] → [MCP サーバ] → [MCP サーバを有効にする] で起動します。
    起動後の [接続情報...] で、Claude Code や Codex CLI から接続するための
    mcp.json の内容を確認・コピーできます。サーバはこの PC の 127.0.0.1
    だけで待ち受けます。接続に使うトークンは他人に渡さないでください。


--------------------------------------------------------------------------------
  2-11. コンポジション メニュー (After Effects 風機能)
--------------------------------------------------------------------------------

  ● シェイプレイヤー追加
    長方形 / 楕円 / 星形 / ポリゴンなどを配置。
  ● パーティクルエフェクト追加
    雪・火花・煙などのプリセット。
  ● テキストアニメーション追加
    タイプライター / フェード / スライドなどのテキストアニメ。
  ● トランスフォームキーフレーム編集
    位置・スケール・回転・不透明度を時間軸でアニメ。
  ● カメラモーション...
    プロジェクト全体の 3D カメラ (位置・注視点・焦点距離 (px)・ロール) とドリー / パン / 周回 /
    手ぶれのプリセットを設定します。「真の透視投影 (回転・注視点・ロールを反映)」を ON に
    すると 3D レイヤーの回転・カメラの向き・ロールが本来の透視で描かれ、プレビューと書き出しの
    両方に効きます。既定 OFF で、OFF のときは従来と同じ描画です。
  ● ダイナミックズーム…
    開始枠と終了枠 (またはズームイン/アウト・パンのプリセット) を指定して、
    位置・スケールのキーフレームを一度に作成する Ken Burns 風の機能です。
    枠は常にキャンバスのアスペクト比に固定されます (高さを指定しても無視)。
  ● マスク追加
    矩形 / 楕円 / ポリゴン マスクで一部だけを表示。
  ● ワープ / 歪みエフェクト
    メッシュワープ / パペットピン / バルジ / ピンチなど。
    「ワープ / 歪みエフェクト…」では 種類 (ワープ: ウェーブ / リップル / 球面化 / 魚眼 / ピンチ) と
    最初のパラメータ (振幅や量) を指定して、選択中の映像クリップに追加します (Ctrl+Z 1 回)。
    残りのパラメータはエフェクトコントロール パネルで調整します。
  ● エクスプレッション
    プロパティを式で制御 (例: wiggle(2, 10))。
    Wave 16 から、wiggle と式はクリップ自身が持ち、書き出しにも乗ります (ファイル指定ジョブでの式の音声レベルは
    Wave 17 から実際のレベル。「Wave 16 の変更」を参照。US-1504 / US-1505)
  ● 選択をプリコンポーズ
    選択したクリップをひとつのコンポジションにまとめます。
  ● 整列 / 均等配置
    選んだクリップを 左 / 水平中央 / 右 / 上 / 垂直中央 / 下 に整列、または水平 / 垂直に均等な
    間隔で配置します。位置だけが変わり、スケールや回転はそのままです。「整列」は 1 つ選んだ
    だけでも有効ですが、「均等配置」は 3 つ以上選んだときだけ有効になります。
    Wave 8 から、親子付け (親レイヤー) やキーフレームのあるクリップでも、画面に実際に描かれて
    いる位置を基準に揃います (従来は親やキーフレームを無視した値で計算していたため、画面上では
    揃いませんでした)。親があるクリップは親を介して動かし、位置にキーフレームがあるクリップは
    再生ヘッド位置にキーを追加して動かします。自動回転 (Auto Orient) のクリップは編集後の
    範囲を基準に揃えます。目標の位置に届かないクリップは変更されず、「N 個のクリップは整列位置に
    合わせられないため変更しませんでした。」がステータスバーに出ます。1 回の操作は Ctrl+Z 1 回です。
    Wave 9 から、親素材がオフライン (ファイルが無い) の親付きクリップ、同じトラックで親が別の
    クリップと重なる時刻、トランジションの借用区間のクリップも、書き出しの描画と同じ親の扱いで
    揃います (従来はこの 3 つでずれることがありました)。選んだクリップ自身のキーフレームも、
    書き出しと同じ時刻で評価されます。
    ● 制限事項: V1 上のキーフレーム付きクリップがトランジションの借用区間にあるときは、
      クリップ本来の範囲 (0 秒〜クリップ長) にクランプした時刻で評価します (描画は借用区間の時刻で評価するため、ずれることがあります)。親素材は存在するがデコードできないときは、
      整列は親ありとして計算し、描画は親を省くためずれることがあります。
    ★挙動変更 (Wave 11) 親付きクリップのプレビューは、書き出しと同じ判定 (parentLayerAt) で親を採用します。一時
    停止中の CPU のみのプレビューで無効化した親に追従しなくなり、トランジションの重なり区間で incoming 側のクリ
    ップを親にした子は親なしになります。親のフレームが取れないときも親を採用しません。プレビューだけが変わり、書
    き出しは変わりません。
  ● パペットピンを編集 / パペットピンをリセット
    映像クリップを選んで「パペットピンを編集」にチェックを入れると、プレビュー上でクリック
    してピンを追加し、ドラッグするとその周囲のメッシュが対話的に変形します (既定はオフ)。
    右クリックでピンを削除、「パペットピンをリセット」で全消去します。プレビューと書き出しが
    一致する CPU 処理です。クリップ未選択やロック中のトラックでは有効にできません。
    Wave 8 から、プレビュー上のクリック位置は、描画と同じ拡大縮小・オフセット・回転・フィット
    (contain / cover) を含むクリップ変換で素材の座標へ対応づけられます。拡大や回転をしたクリップでも
    ピンはクリックした場所に付きます (従来は変換を無視していたためずれました)。キャンバスの
    サイズが変わってもハンドルが追従し、スケール 0 のクリップでは操作できません。contain の
    余白部分をクリックしてもピンは付きません。保存済みのピンの位置は変わりません。
    Wave 9 から、親素材がオフラインの親付きクリップ、親が別クリップと重なる時刻、トランジションの
    借用区間でも、ハンドルやピンの位置は書き出しの描画位置 (tlrender::renderFrameAt) と一致します (メッシュワープも同じ)。


  ● メッシュワープを編集 / メッシュワープをリセット…
    映像クリップを選んで「メッシュワープを編集」にチェックを入れると、プレビューに
    格子状のハンドルが出ます。ハンドルをドラッグすると、その部分の絵が引き伸ばされ
    ます (1 回のドラッグが Ctrl+Z 1 回分です)。編集中はプレビューが CPU 処理に
    切り替わるので、書き出しと同じ絵を見ながら調整できます。
    「メッシュワープをリセット…」で格子の細かさを 3 / 4 / 6 から選び直せます (既定 4)。
    クリップを選んでいないときやトラックがロックされているときは有効にできません。
    別のプロジェクトを開いたり、別のクリップを選んだりすると編集モードは自動的に
    解除されます。
    Wave 8 から、ハンドルの位置とドラッグ量は、パペットピンと同じくクリップ変換 (拡大縮小・
    オフセット・回転・フィット) を通して素材の座標と対応づけられます。見た目どおりの量だけ
    絵が動きます。スケール 0 のクリップでは操作できません。保存済みの UV は変わりません。
    Wave 9 から、親付きクリップの 3 つの形態 (オフライン親 / 重なり / 借用区間) でも、ハンドルの
    位置は書き出しの描画位置と一致します。
    Wave 11 からはプレビューも書き出しと同じ判定 (parentLayerAt) で親を採用します (上の ★挙動変更 (Wave 11))。

  ● 特殊合成クリップのプレビュー  ★挙動変更 (Wave 8)
    タイムリマップ・トラックマット・Text3D・エクスプレッション・wiggle・ライティングのいずれかを
    持つクリップは、プレビューで特殊な合成経路を通ります。Wave 8 から、この経路でも
    メッシュワープ・パペットピン・クリップのエフェクトスタックがプレビューに反映され、書き出しと
    同じソース時刻・同じ順序で処理されます (従来はこれらが書き出しにだけ現れ、プレビューでは
    見えませんでした)。タイムリマップがクリップの OUT 点を越える場合の OUT 点クランプも書き出しと
    同じです。書き出しの出力は変わっていません。
    ★挙動変更 (Wave 10): ロトスコープ (roto) 付きのクリップは、書き出しにも roto が反映される
      ようになりました (Wave 9 まではプレビューのみ)。詳細は下の「Wave 10 で据え置いた制限事項」の
      先頭の説明を参照。
    ★挙動変更 (Wave 11): roto を持つクリップ、または alpha 付き素材は、色補正 / HSL セカンダリ / カーブ / LUT の
    あと、および FX パックの幾何でない FX のあとでも alpha が保たれます (CPU プレビューと書き出しの両方。入力に
    alpha が無いプロジェクトの書き出しは変わりません)。
    ★挙動変更 (Wave 12): GPU プレビュー (GLPreview) では、この経路のフレームを焼き込み済みとして 1 つの入口から表示
      します。roto の alpha とグレードが二重に掛からなくなります (プレビューだけが変わり、書き出しは変わりません)。
    ● 制限事項: この経路で Echo / ローリングシャッターが必要とするフレームの取得は、
      プレビューが decodeClipFrameAtSourceTime、書き出しが renderClipSourceFrame と別の実装です。


--------------------------------------------------------------------------------
  2-12. クリップの右クリックメニュー
--------------------------------------------------------------------------------

  タイムライン上のクリップを右クリックすると、カット/コピー/削除などと
  合わせて次の項目が使えます (映像・音声クリップ共通)。

  ● 置き換え
    メディアプールで選択中の素材へ、位置とトリムを保ったまま差し替えます。
    [編集] → [クリップをメディアプールの素材で置き換え] と同じ機能です。

  ● ラベルカラー
    なし / 赤 / オレンジ / 黄 / 緑 / シアン / 青 / 紫 / ピンク の 9 項目
    (8 色 + なし) から選び、クリップ本体と下端バーの色分けができます。
    複数選択して一括変更も可能。プロジェクト保存で保持されます。

  映像クリップのみ:

  ● パスに沿って自動回転 (チェック)
    位置キーフレームで作ったモーションパスの進行方向へクリップを自動回転させます。
    既存の回転値・回転キーフレームはオフセットとして加算されます。既定は OFF。

  ● カメラへ自動的に向ける (チェック。3D レイヤーでだけ有効)
    3D レイヤーをプロジェクトカメラの方向へ自動的に向けます。「カメラモーション...」の「真の透視投影」が ON のときだけ
    効き、回転 Z は保たれます。既定は OFF。

  ● シェイプモディファイア…
    シェイプクリップに「リピーター」(コピー数・移動・回転・拡大率・最後のコピーの
    不透明度) と「パスのトリミング」(開始・終了・オフセット) を設定します。
    無効のままなら描画は従来と同一です。

  ● 効果を焼き込んで差し替え…
    クリップの効果・変形を新しいメディア (H.264 MP4 / ProRes MOV) に書き出し、そのファイルに
    差し替えます。Wave 10: roto を持つクリップは形式にかかわらずアルファ付き ProRes 4444 (.mov) で
    焼き込まれ、元のクリップの roto は外れます。ハンドル秒で前後の余白を残せます。リンクした音声クリップも同時に焼き込まれます。
    重ね合わせトランジション付きやクロマキー付きのクリップは焼き込めません。
    ★挙動変更 (Wave 11): 逆再生クリップを、タイムリマップ / 速度ランプ付き、またはハンドルが素材の範囲からはみ
    出す状態で焼き込むと、焼き込み結果の映像と roto マスクが元のタイムラインと同じソースフレームになります (欠
    陥修正。素材の範囲内のハンドルは下の ★挙動変更 (Wave 12) を参照)。順方向のクリップと通常の書き
    出しは変わりません。
    ★挙動変更 (Wave 12): 逆再生クリップを、ハンドル付き (素材の範囲内に収まるものを含む) で焼き込むと、クリップ末尾
      まで映像と roto マスクが元のタイムラインと同じソースフレームになります。焼き込みの fps がストリームの fps より
      高く素材末尾に達する焼き込みは、末尾で最後のフレームを保持します (書き出し結果が変わるのはこの焼き込みだけです)。

  ● 元のクリップに戻す
    焼き込んで差し替えたクリップを、効果付きの元のクリップに戻します (Ctrl+Z 1 回でも戻ります)。Wave 12 から、焼き込
    み前のクリップに roto があれば元の roto も戻ります。

  音声クリップのみ:

  ● クリップ EQ… (Wave 12 追加)
    音声クリップエディタの EQ パネルを開きます (「クリップ EQ」チェックと 4 バンドの周波数 / ゲイン / Q。既定はオフ)
    。チェックの切り替えや値の変更は 1 操作 = Ctrl+Z 1 回です (元に戻すの表示は「クリップ EQ を変更」)。再生と書き出
    しのミックスに掛かります。入れ子のクリップは子の設定を優先し、子がオフなら親の設定を使います (直列にはなりません
    )。


  ● 音声トランジション > クロスフェード (コンスタントパワー)… / フェードイン… / フェードアウト…
    継ぎ目や先頭・末尾に等パワーのフェードを明示的に付けます (0.1〜5.0 秒、既定 0.5)。
    クロスフェードは隣接クリップがあるときだけ選べ、前後のクリップが実際に重なって鳴ります
    (Center / Start / End at Cut で重なり位置を選択。余白が足りないと短縮されます)。
    プレビューと書き出しの両方に効きます。

  ● ダイアログレベラー…
    会話の短時間ラウドネスを解析し、目標 LUFS (既定 -18) へ平準化する音量エンベロープを
    生成します。無音区間は持ち上げません。既にエンベロープがある場合は上書き確認が出ます。

  ● ミュージックリミックス…
    BGM をビート境界で組み替えて、指定した目標尺に自動で合わせます。先頭と末尾は元のまま、
    継ぎ目にはコンスタントパワーのクロスフェードが付きます。ビートが 2 個未満だと適用できません。

  ● ノイズプリントを取得 (イン点〜アウト点) / ノイズプリントで除去…
    クリップ内にイン点・アウト点を打ってノイズだけの区間を採取し、「ノイズプリントで除去…」で
    除去量と下限 (dB) を指定してクリップ全体からそのノイズをスペクトル減算します。
    結果は別の .wav に保存して差し替えるので、Ctrl+Z 1 回で元の音源に戻ります。

  Q1. 動画をカットして不要な部分を削除したい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. [開く] で動画をタイムラインに配置
   2. タイムライン下部のシークバーで不要部分の開始位置へ
   3. S キー (または [分割] ボタン) でカット
   4. 不要部分の終了位置へ移動し、再度 S キーでカット
   5. 中央の不要クリップを選択して Delete
   6. Shift + Delete なら後ろのクリップが前に詰まる (リップル削除)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q2. テロップ (字幕) を入れたい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. テロップを入れたい位置へ再生ヘッドを移動
   2. クリップを選択
   3. T キー (または [テキスト] ボタン) を押す
   4. ダイアログで文字・フォント・色・アウトライン・位置を設定
   5. OK を押すとクリップに紐づいたテロップとして登録

   既に作った字幕ファイル (.srt / .vtt) があれば
   [挿入] → [字幕をインポート] で一括登録できます。


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q3. 色調補正をしたい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. 対象クリップを選択
   2. Ctrl + G (または [色補正] ボタン)
   3. スライダーで 明るさ・コントラスト・彩度・色温度 などを調整
     - プレビューには GPU シェーダーでリアルタイム反映されます
   4. OK を押すとそのクリップに色補正設定が保存されます


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q4. 動画を書き出したい (エクスポート)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. タイムラインに編集内容が揃っている事を確認
   2. Ctrl + E (または [出力] ボタン)
   3. ダイアログでコーデック・ビットレート・出力先を設定
      - YouTube アップロード向けなら H.264 / 10 Mbps 程度が一般的
      - 高画質保存なら H.265 / 20 Mbps 以上
   4. エクスポート実行。進捗はプログレスバーで確認
   5. キャンセルも途中で可能


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q5. 長い動画の中から無音部分を自動で削除したい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. 対象クリップを選択
   2. [ツール] → [自動ジャンプカット]
   3. 確認ダイアログで Yes
   4. 無音区間が自動検出されてカットポイントが生成されます
   5. 必要に応じて手動で S キーで分割 → 削除


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q6. J / K / L でプロ風の再生コントロールをしたい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   プロの編集ソフト (Premiere Pro / Final Cut など) と同じ操作感です。

   - K:       再生 / 一時停止
   - L:       順方向再生 (連打で 2x → 4x → 8x → 16x)
   - J:       逆方向再生 (連打で -2x → -4x → ...)
   - L → K:   停止
   - J → K:   停止
   - I:       イン点マーク (選択範囲の始まり)
   - O:       アウト点マーク (選択範囲の終わり)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q7. 動画にマーカーを付けて YouTube チャプターを作りたい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. 章の開始位置に再生ヘッドを移動
   2. Ctrl + M でマーカー追加
   3. 名前を入力、種類で [Chapter] を選択
   4. 必要な数だけ繰り返す
   5. [マーカー] → [YouTube チャプターをエクスポート] で
      YouTube 説明欄用のテキストを出力

      例:
        00:00 イントロ
        02:30 本題
        10:15 まとめ

  Q8. 動画の一部をゆっくり再生 (スローモーション) にしたい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   方法 A: クリップ全体の速度を変える
     1. 対象クリップを選択
     2. [編集] → [再生速度を設定]
     3. 0.5x (半分速度) などを入力

   方法 B: 速度を徐々に変える (スピードランプ)
     1. 対象クリップを選択
     2. [ツール] → [スピードランプ]
     3. 開始速度・終了速度・イージングを設定


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Q9. プロジェクトを保存して後で再開したい
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   1. Ctrl + S でプロジェクトを保存 (.veditor 形式)
   2. 次回: [ファイル] → [プロジェクトを開く] で読み込む
   3. 自動バックアップは 2 分おきに ~/.veditor/autosave/ 配下へ保存されます
      クラッシュした場合は次回起動時に復旧ダイアログが出ます

  Wave 10 で据え置いた制限事項
================================================================================

  Wave 17 の変更 (既存プロジェクトにも効くもの。書き出しの結果が変わるものは「書き出し例外」と明記):

  ● 書き出し例外: 3D テキストを持つクリップの書き出しに 3D テキストが乗ります (ライブ Timeline の書き出し (MCP の
    export_video を含む)、レンダーキューのファイル指定、バッチ書き出しの File)。従来は 3D テキストはプレビュー (特殊合成
     / GLPreview) だけに乗り、書き出しには乗りませんでした。3D テキストを設定していた既存プロジェクトの書き出し結果が変
    わります。重なりトランジションの相手側のクリップでも描かれます。スマートレンダーは 3D テキストを持つクリップをストリ
    ームコピーしません (US-1707 / US-1720)。ブラシだけを持つクリップはスマートレンダーの判定 (SmartRender.cpp:448 /
    :474) で弾かれないため、ストリームコピーされるとブラシが乗りません (修正は Wave 18)。
  ● 3D テキストの書き出しでの合成点は、clip mask を掛けた後、変換 (位置 / スケール / 回転 / 不透明度) の前です (利用者判
    断 M)。プレビューの特殊合成経路は clip mask を一切掛けないため、mask を設定したクリップでは書き出しだけが素材を mask
    で切ります (3D テキストはどちらでも mask で切られません)。プレビューの 3D テキストが proxy で描かれるのは、押し出し
    (extrusion) を有効にした 3D テキストだけです (Text3DLayer.cpp:379)。proxy になるのはフレームの長辺がしきい値を超えた
    ときで (Text3DLayer.cpp:383)、しきい値は QSettings の preview/text3dProxyThreshold (既定 1280。MainWindow.cpp:8556)
    です。proxy は縦横比を保ったまま min(1/2, 640 / 長辺) の倍率で縮小されるため、長辺は 640 以下になり
    (Text3DLayer.cpp:371)、16:9 で長辺が 1280 を超えるフレーム (例: 1920 x 1080 や 3840 x 2160) では 640 x 360 になりま
    す。書き出しはフル解像度で描くため、プレビューと書き出しが画素まで一致するのは、押し出しを無効にした 3D テキストか、
    長辺がしきい値以下のフレームだけです。Echo の過去フレームには 3D テキストもブラシも入りません (US-1707 / US-1708)。
    プレビューの特殊合成経路 (buildSpecialClipComposite) は上位のトラックを手前に重ねます (zOrder = トラック番号。
    MainWindow.cpp:8789、MainWindow.cpp:8831-8833 で昇順に並べる)。書き出しは V1 を手前にする V1-wins の重なり順です
    (TimelineFrameRenderer.cpp:3054)。このため、複数のトラックで不透明なレイヤーが重なる所ではプレビューと書き出しが異な
    ります (3D テキストの有無によらず。US-1707 の run2 で maxDiff 117 を計測)。HEAD の制限で、修正は Wave 18 に持ち越し
    ます。G13 の一致検証が確かめるのは、重ならない配置だけです。
  ● 書き出し例外: ブラシ (ブラシアニメーション) を持つクリップの書き出しにブラシが乗ります (全クリップ分。経路は 3D テキ
    ストと同じ)。従来はプレビューだけに乗り、書き出しには乗りませんでした。ブラシを設定していた既存プロジェクトの書き出
    し結果が変わります。ブラシは roto の後、grade / vfx / fx の前の素材段階で描かれるため、grade / fx を持つクリップでは
    ブラシにも grade / fx が掛かります。書き出しのブラシの進行度 (brush_progress) はクリップ時間のキーフレームで決まり、
    プレビューの進行度も再生位置に追従するようになりました (従来は時刻 0 の値のまま。プレビューの挙動変更で、この部分は
    書き出しの結果を変えません。US-1708)。
  ● プレビューのブラシは、通常のプレビューでは選択中のクリップ 1 本だけで、合成済みキャンバス (特殊合成) では全トラック
    の上に描かれます (HEAD の制限。書き出しは全クリップのブラシを素材段階で描くため異なります。修正は Wave 18)。プロジェ
    クトカメラの焼き込み (trueProjection) では、プレビューも書き出しと同じレンダラー (tlrender::renderFrameAt、
    GLPreview.cpp:2070) で全クリップのブラシを素材段階で描き、選択中のクリップのブラシを重ねて描くことはしません
    (GLPreview.cpp:1226。US-1708)。シェーダの grade と CPU の grade の画素一致は、平坦な入力での水準の確認
    (GradeKeyframeSelftest / offset_wheel_selftest) だけで、画素ごとの一致は確認していません。
  ● RenderInPlace は 3D テキストとブラシを焼き込み画像に含めず、差し替えクリップに残してレンダラーが描きます
    (brush_progress のキーフレームも差し替え側に残ります。RenderInPlace.cpp:41-42 (text3DConfig / brushData は差し替えク
    リップへコピー)、:58 (brush_progress は残す)。US-1720)。grade / fx を持つクリップでは、書き出しがブラシを grade / fx
    の前の素材段階で描く (ブラシにも grade / fx が掛かる) のに対し、焼き込み後は grade / fx が焼き込まれた絵の上にブラシ
    が描かれるため、ブラシの見え方が変わります (Wave 18 の検討事項)。
  ● 3D テキストの設定とブラシのデータはクリップ自身が持つようになり (Wave 16 の wiggle / 式と同じ形)、コピー・複製
    ・貼り付けで複製先に引き継がれます (従来は MainWindow が位置で持つサイドカーでした)。ブレードなど分割の右片に
    は付きません (左片に残ります)。設定の確定は undo 点 1 つです。旧形式のプロジェクト節 (text3DClipEntries /
    brushAnimations) は新ビルドが読み込み時にクリップへ移し、保存では書きません。非アクティブなシーケンスの旧節は
    移行されず、読み込みで失われます (wiggle の旧節と同じ。US-1706)。
  ● 旧ビルドで Wave 17 のプロジェクトを開いて再保存すると、クリップの text3D / brush のキーが失われます (旧ビルドでも開
    けますが、新ビルドで保存した 3D テキストの設定とブラシのアニメーションは読み込まれず、再保存すると消えます)。
  ● 書き出し例外 (欠陥修正): ファイルから書き出すジョブ (レンダーキューのファイル指定 / バッチの File) がプロジェクトの
    カメラ (真の透視投影、カメラへ自動的に向ける設定、カメラ解析のアニメーション) を使うようになり、ライブの書き出しと同
    じ絵になります。従来はカメラが渡らず、カメラを使うプロジェクトの絵がライブの書き出しと異なりました (US-1715)。
  ● 書き出し例外: ファイルを指定したジョブ (レンダーキューのファイル指定 / バッチの File) の式の audioLevel() が、0 では
    なくリンク音声の実際のレベルで評価されます (Wave 16 の利用者判断 D の制限の解消。US-1709)。入れ子シーケンスの中のク
    リップの式の audioLevel() は従来どおり 0 です。audioLevel() を含む式を持つクリップは、リンクグループの最初の音声だけ
    を、音声エンベロープの公開時に背景で先にデコードします (式を使わないプロジェクトでは新たなデコードは起きません。

  ● 起動時に復旧ダイアログが出る
    前回異常終了した時の自動保存ファイルがあるためです。
    必要なら Yes で復旧、不要なら No で無視して新規作業に進めます。

  ● 動画が落ちる・フリーズする
    対応コーデックでないか、プロキシが必要な 4K/8K 素材の可能性。
    [ツール] → [プロキシ生成] で軽量版を作ってから編集してください。

  ● ログファイル
    クラッシュ時のログは以下に保存されます:
      C:\Users\<ユーザー名>\.veditor\logs\veditor_YYYYMMDD_HHMMSS.log
    スタックトレース付きで記録されるので、バグ報告に添付してください。

  ● 自動保存ファイル
    C:\Users\<ユーザー名>\.veditor\autosave\
    最大 5 世代まで残ります。

  ● プロキシファイル
    C:\Users\<ユーザー名>\.veditor\proxies\
