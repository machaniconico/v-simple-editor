# VFX 素材

黒背景の VFX 素材フッテージです。上のビデオトラックに置いて
**合成モードを Screen（または加算）にすると黒が抜けて**、炎や煙だけが下の映像に乗ります。
実際の VFX 制作で最も一般的な手法です。

AI 動画生成 (Magnific / Seedance 2.0) で作成し、**合成素材として成立しているかを
ffprobe で全フレーム実測して確認済み**です。すべて 1920x1080 / 24fps。

| ファイル | 内容 | 背景の最小輝度 | 素材本体の輝度 |
|---|---|---:|---:|
| `fire_01.mp4` | 立ち上る炎 | 8 | 225 |
| `smoke_01.mp4` | 白煙のプルーム | 3 | 202 |
| `explosion_01.mp4` | 爆発（火球＋破片） | 5 | 244 |
| `sparks_01.mp4` | 飛び散る火花 | 3 | 246 |
| `lightning_01.mp4` | 分岐する稲妻 | 8 | 210 |
| `water_01.mp4` | 水しぶき | 0 | 237 |
| `dust_01.mp4` | 舞う塵・光の粒子 | 10 | 230 |
| `lightleak_01.mp4` | 光の筋（ライトリーク風） | 12 | 249 |

背景は最小輝度 0〜12 でほぼ純黒、素材本体は 202〜249 と十分明るいため、
Screen 合成でクリーンに抜けます。

## 黒レベルの引き締めについて

素材によってはフレームごとに背景が輝度 15 程度まで浮くことがあります
（特に `lightning_01`）。そのまま Screen 合成すると背景が薄く乗る「黒浮き」になるため、
**黒レベル引き締めのしきい値は 16 が既定**です。この値なら
最も黒が浮く素材でも背景を確実に 0 へ落とし、かつ素材本体（輝度 200 超）には一切触れません。

## 素材の追加

このフォルダに動画ファイル（mp4 / mov / webm）を置くと、
エフェクトライブラリに自動的に並びます。ファイル名の接頭辞からカテゴリを推定するので、
`fire_02.mp4` のように既存の命名に合わせると分類されます。
推定できない名前でも「その他」として登録され、捨てられることはありません。
